# History

## 2026-11-04 09:45 UTC — Pop the Stack root natively to the previous split column
**Asked:** Replace the fade of the collapsed root pop with a native pop: both headers move with their screens, the Back follows the transition, cancel restores the Stack header exactly, and a Back tap animates without an empty header.
**Did / why:** The native pop replaced the fade. The fade kept the Stack header items visible, but UIKit still drew two headers. When collapsed, the content column shares the bar of the primary navigation controller. Before the root swipe or the root Back starts the pop, the shared bar shows the Stack root title and Back, and the Stack header is masked without a layout change, so UIKit animates one bar like a plain pop. This is prepared in `gestureRecognizerShouldBegin`, because UIKit starts the pop from its own gesture target and later changes are too late. If no transition starts, the column is restored in the same run loop turn; a possible one-frame flicker was not measured. Header items, a search bar and a custom title hide during the pop; this was accepted and is listed in `SPLIT_STACK_TODO.md`. Pops that start from JavaScript keep the fade. Screens is unchanged. Tested on iPhone 17 Pro and iPad Pro 13-inch, not on the iPhone Duo.

## 2026-11-03 18:25 UTC — Fix the root swipe header overlap and the expanded sidebar button
**Asked:** Fix issues 1 and 2 of `SPLIT_STACK_TODO.md`: two headers overlap during an interactive swipe back from the Stack root, and the Stack header shows a sidebar button in the expanded layout.
**Did / why:** Collapsed: the content column navigation controller is nested in the primary one and shares its bar. While the bar is hidden, UIKit still animates it during the root pop and draws the previous column title over the leaving Stack header. Showing the bar again, animated or not, did not remove that copy, and UIKit resets the bar alpha during the transition. The column now hides the shared bar with an empty layer mask until the pop ends. A cancelled pop restores the Stack header, its Back and the hidden bar. A completed pop fades in the previous column header, and after a Back tap no header shows for about 0.3 s before the fade. This matches a plain Stack pop to a screen with a header on iOS 26, where the incoming header does not show during the swipe. The header does not move with its screen, so this is the crossfade fallback, not a native pop. Expanded: UIKit shows its sidebar button in the content column only when it is alone or other columns overlay it. The native column now reports `showsSidebarButton` from the display mode, so the Stack header adds the button only in that case. Screens is unchanged. Tested on iPhone 17 Pro (collapsed) and iPad Pro 13-inch (expanded), not on the iPhone Duo. Native tests need `RNS_GAMMA_ENABLED=1 pod install` in `apps/bare-expo/ios` and `-lc++` in the test bundle link flags.
