## Usage

### Basic switch

<ComponentExample
  title="SwitchExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-switch-basic-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-switch-basic-android-dark.webp',
    alt: 'A switch in the off position',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-switch-basic-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-switch-basic-ios-dark.webp',
    alt: 'A switch in the off position',
  }}>

```tsx
import { useState } from 'react';
import { Host, Switch } from '@expo/ui';

export default function SwitchExample() {
  const [enabled, setEnabled] = useState(false);

  return (
    <Host matchContents>
      <Switch value={enabled} onValueChange={setEnabled} />
    </Host>
  );
}
```

</ComponentExample>

### With label

When `label` is provided, the switch is rendered alongside its text in a labeled row.

<ComponentExample
  title="LabeledSwitchExample.tsx"
  android={{
    src: '/static/images/expo-ui/examples/universal-switch-labeled-android-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-switch-labeled-android-dark.webp',
    alt: 'An on switch with the label Enable notifications',
  }}
  ios={{
    src: '/static/images/expo-ui/examples/universal-switch-labeled-ios-light.webp',
    darkSrc: '/static/images/expo-ui/examples/universal-switch-labeled-ios-dark.webp',
    alt: 'An on switch with the label Enable notifications',
  }}>

```tsx
import { useState } from 'react';
import { Host, Switch } from '@expo/ui';

export default function LabeledSwitchExample() {
  const [notifications, setNotifications] = useState(true);

  return (
    <Host matchContents={{ vertical: true }} style={{ width: '100%' }}>
      <Switch label="Enable notifications" value={notifications} onValueChange={setNotifications} />
    </Host>
  );
}
```

</ComponentExample>
