`Pedometer` from `expo-sensors` uses the system step counter sensor for live updates, and the Recording API on Android/Core Motion on iOS for step history.

> **warning** Pedometer is not available in Expo Go for Android. Expo Go does not include the `ACTIVITY_RECOGNITION` permission that Pedometer needs. With this permission, Google Play could classify Expo Go as a health app. To use Pedometer on Android, create a [development build](/develop/development-builds/introduction/).

iOS keeps collecting step history automatically (up to seven days). On Android, step history requires the [`pedometerPlayServicesEnabled`](#configurable-properties) config plugin option, Google Play services Recording API support, and an active `subscribeRecordingAsync()` subscription. Unsubscribing makes previously collected history inaccessible, and Android retains up to 10 days since the latest subscription. The subscription helpers (`subscribeRecordingAsync()` / `unsubscribeRecordingAsync()`) are no-ops on iOS.

## Configuration in app config

You can configure `Pedometer` from `expo-sensors` using its built-in [config plugin](/config-plugins/introduction/). The plugin allows you to configure properties that cannot be set at runtime and require building a new app binary to take effect.

<ConfigPluginExample>

```json app.json
{
  "expo": {
    "plugins": [
      [
        "expo-sensors",
        {
          "motionPermission": "Allow $(PRODUCT_NAME) to access your device motion",
          "pedometerPlayServicesEnabled": true
        }
      ]
    ]
  }
}
```

## Usage

<SnackInline label='Pedometer' dependencies={['expo-sensors']} >

```jsx
import { useState, useEffect } from 'react';
import { Platform, StyleSheet, Text, View } from 'react-native';
import { Pedometer } from 'expo-sensors';

export default function App() {
  const [isPedometerAvailable, setIsPedometerAvailable] = useState('checking');
  const [isPedometerHistoryAvailable, setIsPedometerHistoryAvailable] = useState('checking');
  const [pastStepCount, setPastStepCount] = useState(0);
  const [currentStepCount, setCurrentStepCount] = useState(0);

  const subscribe = async () => {
    const isAvailable = await Pedometer.isAvailableAsync();
    setIsPedometerAvailable(String(isAvailable));
    const isHistoryAvailable = await Pedometer.isRecordingAvailableAsync();
    setIsPedometerHistoryAvailable(String(isHistoryAvailable));

    if (isHistoryAvailable) {
      if (Platform.OS === 'android') {
        await Pedometer.subscribeRecordingAsync();
      }
      const end = new Date();
      const start = new Date();
      start.setDate(end.getDate() - 1);

      const pastStepCountResult = await Pedometer.getStepCountAsync(start, end);
      setPastStepCount(pastStepCountResult.steps);
    }

    if (isAvailable) {
      return Pedometer.watchStepCount(result => {
        setCurrentStepCount(result.steps);
      });
    }
  };

  useEffect(() => {
    const subscriptionPromise = subscribe();

    return () => {
      subscriptionPromise.then(subscription => subscription?.remove());
    };
  }, []);

  return (
    <View style={styles.container}>
      <Text>Pedometer.isAvailableAsync(): {isPedometerAvailable}</Text>
      <Text>Pedometer.isRecordingAvailableAsync(): {isPedometerHistoryAvailable}</Text>
      <Text>Steps taken in the last 24 hours: {pastStepCount}</Text>
      <Text>Walk! And watch this go up: {currentStepCount}</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    marginTop: 15,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```
