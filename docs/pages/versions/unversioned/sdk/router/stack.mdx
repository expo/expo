An Expo Router API that provides Stack navigator, toolbar, and screen components.

> See the [Expo Router](./index) reference for installation and configuration.

## Usage

```tsx
import { Stack } from 'expo-router';

export default function Layout() {
  return <Stack />;
}
```

### Required screens below a screen

> **warning** This API is unstable and can change in a minor release.

A deep link or a push from another screen can open a screen with nothing below it in the stack. Then the back action leaves the stack. Use the `unstable_requiredScreensBelow` prop of `Stack.Screen` in a layout to list the screens that must be below that screen.

```tsx app/_layout.tsx
import { Stack } from 'expo-router';

export default function Layout() {
  return (
    <Stack>
      <Stack.Screen name="index" />
      <Stack.Screen name="[id]" />
      <Stack.Screen
        name="[id]/comments"
        unstable_requiredScreensBelow={[
          'index',
          { name: '[id]', params: { id: '1' } },
        ]}
      />
    </Stack>
  );
}
```

Each entry is a screen name from the same `Stack`, such as `'[id]'`. It is not an href, such as `'/1'`.

When the user opens **/42/comments**, the stack contains `index`, `[id]` with `id` set to `1`, and `[id]/comments` with `id` set to `42`.

- The stack adds a listed screen only when no route at or below the focused screen has the same name and the same path params.
- The stack adds the screens directly below the focused screen, in the listed order.
- A screen listed by name gets the matching path params of the focused screen. A screen listed as an object uses only its own `params`. It does not get the path params of the focused screen.
- The stack skips names that are not routes of the stack.
- Screens that the stack already added stay when the prop changes or is removed.
- Right after the screen renders, before the stack adds the screens to the navigation state, `router.canGoBack()` returns the previous result.

The prop works only on a `Stack.Screen` in a layout. It has no effect on a `Stack.Screen` in a page.
