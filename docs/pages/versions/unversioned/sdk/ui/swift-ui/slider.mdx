## Usage

> **Note:** `Slider` is a flexible-width component, it expands to fill available horizontal space and does not have an intrinsic width. When using `matchContents` on the `Host`, you should apply a [`frame`](modifiers/#frameparams) modifier on the `Slider` to give it an explicit width. Alternatively, give the `Host` an explicit size using `style` (for example, `style={{ width: 300 }}` or `style={{ flex: 1 }}`), or place the `Slider` inside a SwiftUI container like `Form` that provides width constraints.

### Basic slider

<ComponentExample
  title="BasicSliderExample.tsx"
  src="/static/images/expo-ui/examples/slider-basic-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/slider-basic-ios-dark.webp"
  alt="A slider with its thumb at the midpoint of the track">

```tsx
import { useState } from 'react';
import { Host, Slider } from '@expo/ui/swift-ui';

export default function BasicSliderExample() {
  const [value, setValue] = useState(0.5);

  return (
    <Host style={{ flex: 1 }}>
      <Slider value={value} onValueChange={setValue} />
    </Host>
  );
}
```

</ComponentExample>

### Slider with custom range

<ComponentExample
  title="CustomRangeSliderExample.tsx"
  src="/static/images/expo-ui/examples/slider-custom-range-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/slider-custom-range-ios-dark.webp"
  alt="A slider over a range of 0 to 100 with its thumb three quarters of the way along">

```tsx
import { useState } from 'react';
import { Host, Slider } from '@expo/ui/swift-ui';

export default function CustomRangeSliderExample() {
  const [value, setValue] = useState(75);

  return (
    <Host style={{ flex: 1 }}>
      <Slider
        value={value}
        min={0}
        max={100}
        onValueChange={setValue}
      />
    </Host>
  );
}
```

</ComponentExample>

### Slider with step

Use the `step` prop to define discrete increments. Set `step` to `0` for continuous values.

<ComponentExample
  title="SteppedSliderExample.tsx"
  src="/static/images/expo-ui/examples/slider-stepped-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/slider-stepped-ios-dark.webp"
  alt="A slider with its thumb at the far left, at the minimum value of zero">

```tsx
import { useState } from 'react';
import { Host, Slider } from '@expo/ui/swift-ui';

export default function SteppedSliderExample() {
  const [value, setValue] = useState(0);

  return (
    <Host style={{ flex: 1 }}>
      <Slider
        value={value}
        min={0}
        max={100}
        step={10}
        onValueChange={setValue}
      />
    </Host>
  );
}
```

</ComponentExample>

### Slider with labels

You can add labels to describe a slider's purpose and to mark the minimum and maximum value positions.

<ComponentExample
  title="LabeledSliderExample.tsx"
  src="/static/images/expo-ui/examples/slider-labeled-ios-light.webp"
  darkSrc="/static/images/expo-ui/examples/slider-labeled-ios-dark.webp"
  alt="A slider flanked by a 0 label on the left and a 100 label on the right">

```tsx
import { useState } from 'react';
import { Host, Slider, Text } from '@expo/ui/swift-ui';

export default function LabeledSliderExample() {
  const [value, setValue] = useState(50);

  return (
    <Host style={{ flex: 1 }}>
      <Slider
        value={value}
        min={0}
        max={100}
        label={<Text>Volume</Text>}
        minimumValueLabel={<Text>0</Text>}
        maximumValueLabel={<Text>100</Text>}
        onValueChange={setValue}
      />
    </Host>
  );
}
```

</ComponentExample>
