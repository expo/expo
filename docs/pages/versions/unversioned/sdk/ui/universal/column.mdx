A vertical layout container that arranges its children from top to bottom. Delegates to SwiftUI's [`VStack`](../swift-ui/vstack) on iOS, Jetpack Compose's [`Column`](../jetpack-compose/column) on Android, and a flex `View` on web.

```tsx
import { useColorScheme } from 'react-native';
import { Host, Column, Text } from '@expo/ui';

export default function ColumnExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host matchContents>
      <Column spacing={8}>
        <Text textStyle={ink}>First</Text>
        <Text textStyle={ink}>Second</Text>
        <Text textStyle={ink}>Third</Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>

### Alignment

Use [`alignment`](#alignment) to position children along the cross (horizontal) axis.

  }}>

```tsx
import { useColorScheme } from 'react-native';
import { Host, Column, Text } from '@expo/ui';

export default function ColumnAlignmentExample() {
  const colorScheme = useColorScheme();
  const ink = { color: colorScheme === 'dark' ? '#FFFFFF' : '#000000' };

  return (
    <Host matchContents={{ vertical: true }} style={{ width: '100%' }}>
      <Column spacing={8} alignment="center">
        <Text textStyle={ink}>Centered</Text>
        <Text textStyle={ink}>Centered</Text>
      </Column>
    </Host>
  );
}
```

</ComponentExample>

### Size

`style.width` and `style.height` take a number of points, or a percentage of the parent such as `'50%'`. The parent has to be a universal `Row`, `Column`, or `Host` with a size on that axis. If the column takes its size from its children, a child percentage on that axis is ignored. A SwiftUI `VStack` or a Jetpack Compose `Column` ignores a child percentage.

```tsx
import { Host, Column } from '@expo/ui';

export default function ColumnSizeExample() {
  return (
    <Host style={{ flex: 1 }}>
      <Column style={{ width: '100%' }} spacing={8}>
        <Column style={{ width: '100%', height: 24, backgroundColor: '#90CAF9' }} />
        <Column style={{ width: '50%', height: 24, backgroundColor: '#1565C0' }} />
      </Column>
    </Host>
  );
}
```
