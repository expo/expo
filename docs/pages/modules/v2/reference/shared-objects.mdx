A shared object is a native object that JavaScript uses as an instance of a JavaScript class.

## Declare a shared object

<LanguageSupport feature="shared-objects" />

Add `@SharedObject` to a subclass of `SharedObject`, and `@JS` to the members that JavaScript can use. A module exports the class in the `classes` argument of `@ExpoModule`:

```swift
@SharedObject
final class Cache: SharedObject {
  private var values: [String: String] = [:]

  @JS
  init(name: String) {
    // ...
  }

  @JS
  func get(_ key: String) -> String? {
    values[key]
  }

  @JS
  var size: Int {
    values.count
  }
}

@ExpoModule("MyModule", classes: [Cache.self])
public final class MyModule: Module {
  // ...
}
```

The JavaScript class is a property of the module object. Its name is the name of the native class. To use another name, pass it to `@SharedObject`, for example `@SharedObject("NativeCache")`.

```ts
const MyModule = requireNativeModule('MyModule');

const cache = new MyModule.Cache('images');
cache.get('logo');
cache.size;
```

The class must be a subclass of `SharedObject`, directly or not, for example a subclass of `SharedRef<T>`. A class without a superclass is a build error, and the macro shows a fix that adds `: SharedObject`.

## Constructor

`@JS init` is the constructor of the JavaScript class. A class can have one `@JS init`. Without it, JavaScript can't create instances of the class, but native functions can still return them.

A subclass of another `@SharedObject` class gets the `@JS` members of its superclass. A member of the subclass replaces an inherited member with the same JavaScript name. If the subclass isn't `final`, JavaScript can't create it with the `@JS init` of its superclass, so give each subclass that JavaScript creates its own `@JS init`.

## Static members

<LanguageSupport feature="shared-object-static-members" />

`@JS` on a `static` or `class` member binds it to the JavaScript class, not to its instances:

```swift
@SharedObject
final class EncryptionKey: SharedObject {
  @JS
  static func generate(size: KeySize?) async -> EncryptionKey {
    // ...
  }
}
```

```ts
const key = await MyModule.EncryptionKey.generate(256);
```

Static members and instance members bind to different JavaScript objects, so they can have the same name.

## Thread safety

Native code can use a shared object from more than one thread, for example in `.concurrent` functions. So, `@SharedObject` adds an `@unchecked Sendable` conformance when the class isn't `Sendable`. The compiler then doesn't check the mutable state of the class. Keep state that more than one thread uses behind a lock or an actor. For more information, see [Concurrency](/modules/v2/reference/concurrency/).
