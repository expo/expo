The arguments, results, properties, and event payloads of a module convert between JavaScript and native types. This page describes the types that need more than a plain native type. For records and unions, see [Records and unions](/modules/v2/reference/records-and-unions/).

## Enums

<LanguageSupport feature="enums" />

An enum converts to and from a JavaScript string or number. Make the enum implement `Enumerable`:

<CodeBlocksTable tabs={['ImageFormat.kt', 'ImageFormat.swift']}>

```kotlin
enum class ImageFormat(val value: String) : Enumerable {
  JPG("jpeg"),
  PNG("png")
}
```

```swift
enum ImageFormat: String, Enumerable {
  case jpg = "jpeg"
  case png
}
```

</CodeBlocksTable>

In Kotlin, the JavaScript value is the value of the one property of the enum. The property is a `String` or an `Int`. In Swift, the JavaScript value is the raw value of the case, for example a `String` or an `Int`.

## Tuples

<LanguageSupport feature="tuples" />

In Swift, a tuple converts to a JavaScript array or object:

- An unlabeled tuple, such as `(Int, String)`, converts to an array with one item for each element.
- A labeled tuple, such as `(x: Double, y: Double)`, converts to an object with one property for each label.

```swift
@JS
func bounds() -> (width: Double, height: Double) {
  (width: 100, height: 50)
}
```

A tuple can be an argument, a result, a property, a record field, a union payload, an event payload, and an argument or a result of a closure that isn't `async`. A tuple has two or more elements. All elements have labels or none have labels, and each element type converts. Tuples can be in other tuples, optionals, arrays, and dictionaries with `String` keys.

You can use a type alias for a tuple, such as `typealias Span = (start: Int, end: Int)`, only when the body of the `@ExpoModule` or `@SharedObject` class declares the alias. The macro can't see an alias that you declare in another place.

## Closure arguments

<LanguageSupport feature="closure-arguments" />

In Swift, a function or an initializer can take a closure argument. JavaScript passes a function for it. Native code can keep the closure and call it from any thread.

```swift
@JS
func download(url: String, onProgress: @escaping (Double) -> Void) {
  // ...
}

@JS
func transform(_ value: String, using transformer: @escaping (String) throws -> String) throws -> String {
  try transformer(value)
}
```

How the call works depends on the type of the closure:

- A non-throwing closure that returns `Void` returns before JavaScript reads its arguments. Don't change a class instance after you pass it to such a closure.
- A closure that throws or returns a value blocks the caller until the JavaScript function returns. A closure that returns a value must be `throws`, so that an error from JavaScript can reach the caller.
- An `async` closure suspends the caller instead, and waits for the promise that the JavaScript function returns.

## JavaScript values

<LanguageSupport feature="javascript-values" />

In Swift, a `@JS` function can take a JavaScript value without a conversion. Declare the argument as `borrowing JavaScriptValue`:

```swift
@JS
func describe(_ value: borrowing JavaScriptValue) -> String {
  // ...
}
```

A JavaScript value is valid only on the JavaScript thread. So, a `.concurrent` function and a function with `.withAsync` can't take it, and the macro reports such an argument.
