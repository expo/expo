Expo Router provides three ways to respond when a screen gains or loses focus:

| If you want to                                    | Use                           |
| ------------------------------------------------- | ----------------------------- |
| Start and clean up work while a screen is focused | `useFocusEffect`              |
| Update the UI when focus changes                  | `useIsFocused`                |
| Listen for a specific focus or blur event         | `useNavigation().addListener` |

## Run an effect when a screen is focused

Use `useFocusEffect` for work that should run only while a screen is focused, such as a subscription. Wrap the callback in `useCallback` so the effect does not run on every render.

<FileTree files={['src/app/profile.tsx']} />

```tsx src/app/profile.tsx
import { useCallback } from 'react';
import { useFocusEffect } from 'expo-router';

export default function Profile() {
  useFocusEffect(
    useCallback(() => {
      const subscription = subscribeToProfileUpdates();

      return () => subscription.unsubscribe();
    }, [])
  );

  return null;
}
```

The callback runs when the screen gains focus. If the screen is already focused, it also runs when its dependencies change. Return a cleanup function to stop the work when the screen loses focus, the dependencies change, or the component unmounts.

### Pass dependencies to `useFocusEffect`

`useFocusEffect` accepts only one argument. Put dependencies in the `useCallback` dependency array:

```tsx
useFocusEffect(
  useCallback(() => {
    const subscription = subscribeToProfileUpdates(profileId);
    return () => subscription.unsubscribe();
  }, [profileId])
);
```

### Run async work in `useFocusEffect`

Do not make the callback itself `async` because it must return a cleanup function or nothing. Instead, define and call an async function inside the callback:

```tsx
useFocusEffect(
  useCallback(() => {
    let isActive = true;

    async function loadProfile() {
      const profile = await fetchProfile(profileId);
      if (isActive) {
        setProfile(profile);
      }
    }

    loadProfile();
    return () => {
      isActive = false;
    };
  }, [profileId])
);
```

The cleanup prevents a completed request from updating the screen after the effect ends.

## Render based on focus

Use `useIsFocused` when the rendered UI depends on whether the screen is focused. It returns a boolean and re-renders the component when focus changes.

```tsx
import { useIsFocused } from 'expo-router';

export default function Profile() {
  const isFocused = useIsFocused();

  return <ProfileContent showLiveStatus={isFocused} />;
}
```

## Listen for focus and blur events

Use `useNavigation` to run code for a specific `focus` or `blur` event. Subscribe in an effect and remove both listeners in its cleanup:

```tsx
import { useEffect } from 'react';
import { useNavigation } from 'expo-router';

export default function Profile() {
  const navigation = useNavigation();

  useEffect(() => {
    const removeFocusListener = navigation.addListener('focus', recordProfileView);
    const removeBlurListener = navigation.addListener('blur', pauseProfileUpdates);

    return () => {
      removeFocusListener();
      removeBlurListener();
    };
  }, [navigation]);

  return null;
}
```
