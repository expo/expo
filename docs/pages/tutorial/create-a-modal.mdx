A modal presents content above the rest of the app. In general, modals are used to draw a user's attention toward critical information or guide them to take action. A bottom sheet is a type of modal that slides up from the bottom of the screen.

In this chapter, we'll create an emoji picker with the [`BottomSheet`](/versions/latest/sdk/ui/universal/bottomsheet/) component from Expo UI. On Android and iOS, it displays the platform's native bottom sheet. On web, it displays a sheet at the bottom of the page.

## Declare a state variable to show buttons

Before implementing the bottom sheet, we are going to add three new buttons. These buttons are visible after the user picks an image from the media library or uses the placeholder image. One of these buttons will open the emoji picker.

In **src/app/(tabs)/index.tsx**:

1. Declare a boolean state variable, `showAppOptions`, to show or hide the buttons that open the emoji picker, alongside a few other options. When the app screen loads, we'll set it to `false` so the options are not shown before picking an image. When the user picks an image or uses the placeholder image, we'll set it to `true`.
2. Update the `pickImageAsync()` function to set the value of `showAppOptions` to `true` after the user picks an image.
3. In the `onPress` prop of the button with no theme, replace the `alert()` with a function that sets `showAppOptions` to `true`.

import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  const [selectedImage, setSelectedImage] = useState<string | undefined>(undefined);
  /* @tutinfo Create a state variable inside the `Index` component. */
  const [showAppOptions, setShowAppOptions] = useState<boolean>(false);
  /* @end */

    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      setSelectedImage(result.assets[0].uri);
      /* @tutinfo After selecting the image, set the app options to true. */
      setShowAppOptions(true);
      /* @end */

      alert('You did not select any image.');
    }
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
      </View>

      {showAppOptions ? (
        <View />
      /* @end */
      ) : (
        <View style={styles.footerContainer}>
          <Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
          /* @tutinfo Replace the `alert()` with a function that sets `showAppOptions` to `true`. */
          <Button label="Use this photo" onPress={() => setShowAppOptions(true)} />
          /* @end */
        </View>
      /* @tutinfo */)}/* @end */

## Create an emoji picker with a bottom sheet

The bottom sheet allows the user to choose an emoji from a list of available emoji. Create an **emoji-picker.tsx** file inside the **src/components** directory. This component accepts three props:

- `isVisible`: a boolean to determine whether the bottom sheet is visible.
- `onClose`: a function to close the bottom sheet.
- `children`: used later to display a list of emoji.

{/* prettier-ignore */}
```tsx src/components/emoji-picker.tsx
import { PropsWithChildren } from 'react';
import { StyleSheet, Text, View } from 'react-native';
/* @tutinfo Import `BottomSheet` and `RNHostView` from Expo UI. */
import { BottomSheet, RNHostView } from '@expo/ui';
/* @end */

type Props = PropsWithChildren<{
  isVisible: boolean;
  onClose: () => void;
}>;

export default function EmojiPicker({ isVisible, children, onClose }: Props) {
  return (
    <BottomSheet
      isPresented={isVisible}
      onDismiss={onClose}
      snapPoints={/* @tutinfo Open the bottom sheet at about half of the screen height. */['half']/* @end */}
      containerColor="#25292e">
      /* @tutinfo `RNHostView` displays React Native views inside the bottom sheet. */
      <RNHostView>
        <View>
          <Text style={styles.title}>Choose a sticker</Text>
          {children}
        </View>
      </RNHostView>
      /* @end */
    </BottomSheet>
  );
}

const styles = StyleSheet.create({
  title: {
    color: '#fff',
    fontSize: 16,
    marginBottom: 20,
  },
});
```

Let's learn what the above code does:

- The `BottomSheet` component comes from `@expo/ui`, which we installed in the [third chapter](/tutorial/build-a-screen/#use-native-buttons-with-expo-ui). On Android, it displays a Material 3 bottom sheet. On iOS, it displays a SwiftUI sheet. On web, it displays a sheet at the bottom of the page.
- Its `isPresented` prop takes the value of `isVisible` and controls whether the bottom sheet is open or closed.
- Its `onDismiss` prop calls `onClose` when the user closes the bottom sheet. The user can swipe the bottom sheet down or tap outside it. On Android, the back button also closes it. On web, the <kbd>Esc</kbd> key also closes it.
- Its `snapPoints` prop sets the heights where the bottom sheet can rest. The `'half'` value opens it at about half of the screen height.
- Its `containerColor` prop sets the background color of the bottom sheet to match the app's background.
- The `RNHostView` component displays React Native views, such as `<View>` and `<Text>`, inside the bottom sheet.

<Collapsible summary={<>What is <CODE>RNHostView</CODE>?</>}>

On Android and iOS, `BottomSheet` is a native view from Jetpack Compose and SwiftUI. To display React Native views inside it, wrap them in `RNHostView`. It works in the opposite direction of `Host`, which we used in the [third chapter](/tutorial/build-a-screen/#use-native-buttons-with-expo-ui) to display Expo UI components inside React Native views. `BottomSheet` creates its own `Host`, so we don't wrap it in one. For more information, see [`RNHostView`](/versions/latest/sdk/ui/universal/rnhostview/).

</Collapsible>

          <Image source={item} style={styles.image} />
        </Pressable>
      )}
    />
  );
}

    marginBottom: 20,
  },
  image: {
    width: 100,
    height: 100,
  },

Let's learn what the above code does:

- The `emoji` array holds the emoji images. It is outside the component because its value never changes.
- The `<FlatList>` component takes the `emoji` array as the value of the `data` prop. The `renderItem` prop takes each item from the `data` and returns an `Image` component, wrapped by a `<Pressable>`. When the user presses an emoji, `onSelect` receives it, and `onCloseModal` closes the bottom sheet.
- The `numColumns` prop displays the list as a grid with three columns. The `columnWrapperStyle` prop styles each row of the grid.
