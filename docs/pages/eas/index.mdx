Expo Services are deeply integrated cloud services for Expo and React Native apps, from the team behind Expo.

Read the full pitch at [expo.dev/services](https://expo.dev/services), or follow the links below to learn how to get started.

> **info** Service names in these docs start with Expo, for example, Expo Build and Expo Update. The `eas` command, the **eas.json** file, and environment variables such as `EAS_BUILD_PROFILE` keep their names. See [EAS and Expo service names](/eas-to-expo/) for the older and current name of each service.
