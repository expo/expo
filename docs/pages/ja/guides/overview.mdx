このセクションでは、Expo と Expo Application Services（EAS）を使った開発に関する情報を扱います。

## <span className="inline-flex items-center gap-2"><CodeSquare01Icon />開発プロセス</span>

[Expo を使ったアプリの構築](/ja/workflow/overview/)のプロセスについて学び、コアとなる開発ループのメンタルモデルを理解する助けにしてください。このセクションでは、アプリの開発・デプロイ・保守に必要となる、開発プロセス中の追加の設定やワークフローについても詳しく取り上げます。[app config](/ja/workflow/configuration/)、[パーミッション](/ja/guides/permissions/)、[ユニバーサルリンク](/ja/linking/into-your-app/)、[カスタムネイティブコード](/ja/workflow/continuous-native-generation/)、[web](/ja/workflow/web/) などについての詳しい情報が含まれています。

## <span className="inline-flex items-center gap-2"><RouterLogo />Expo Router</span>

[Expo Router](/router/introduction/) ライブラリが提供するさまざまなナビゲーション機能の使い方について学びます。また、このライブラリが提供する包括的な [Hooks API](/versions/latest/sdk/router/#hooks)、および [認証](/router/advanced/authentication/)、[リダイレクト](/router/reference/redirects/)、[テスト](/router/reference/testing/) などのナビゲーションに関するその他の側面についても取り上げます。

## <span className="inline-flex items-center gap-2"><CpuChip01Icon />Expo Modules API</span>

[Expo Modules API](/modules/overview/) を使ってアプリにネイティブモジュールを追加し、使用する方法について学びます。

## <span className="inline-flex items-center gap-2"><GraduationHat02DuotoneIcon />チュートリアル</span>

Expo と EAS のステップバイステップのチュートリアルをお探しの場合は、[チュートリアルセクション](/ja/tutorial/overview/)をご覧ください。[Expo を使ったアプリの構築](/ja/tutorial/introduction/)と [EAS サービスの利用](/ja/tutorial/eas/introduction/)の両方について、包括的なチュートリアルを掲載しています。

## その他のコンテンツ

上記の基本的な内容以外にも、[プッシュ通知](/push-notifications/overview/)など、さらに探求できる機能が数多くあります。また、**Assorted** およびサードパーティの **Integrations** セクションにもガイドを取り揃えています。
