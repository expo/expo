## 新しい Expo アプリを初期化する

新しい Expo アプリを初期化するために [`create-expo-app`](/more/create-expo/) を使います。これは新しい React Native プロジェクトを作成するためのコマンドラインツールです。それでは、ターミナルで次のコマンドを実行してみましょう。

<Terminal
  cmd={{
    npm: [
      '# Create a project named StickerSmash',
      '$ npx create-expo-app@latest StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    yarn: [
      '# Create a project named StickerSmash',
      '$ yarn create expo-app StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    pnpm: [
      '# Create a project named StickerSmash',
      '$ pnpm create expo-app StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
    bun: [
      '# Create a project named StickerSmash',
      '$ bun create expo StickerSmash',
      '',
      '# The CLI asks for an Expo SDK version. Select Latest (SDK 58).',
      '$ Select an Expo SDK version > Latest (SDK 58)',
      '',
      '# Navigate to the project directory',
      '$ cd StickerSmash',
    ],
  }}
/>

このコマンドは [デフォルト](/more/create-expo/#--template) テンプレートを使用して、StickerSmash という名前の新しいプロジェクトディレクトリを作成します。このテンプレートには、Expo Router を含む、アプリ構築に必要な基本的なボイラープレートコードとライブラリが含まれています。チュートリアルの中で必要に応じてライブラリを追加していきます。

<Collapsible summary="デフォルトテンプレートを使用するメリット">

- `expo` パッケージがインストールされた新しい React Native プロジェクトを作成します
- Expo CLI などの推奨ツールが含まれます
- 基本的なナビゲーションシステムを提供するために Expo Router のタブナビゲーターが含まれます
- Android、iOS、web の複数のプラットフォームでプロジェクトを実行できるよう自動的に設定されます
- TypeScript がデフォルトで設定されます

</Collapsible>

## reset-project スクリプトを実行する

{/* vale on */}

このチュートリアルでは、アプリをゼロから構築し、ファイルベースのナビゲーションを追加する基本を理解します。ボイラープレートコードを取り除くために、`reset-project` スクリプトを実行しましょう。

<Terminal
  cmd={{
    npm: ['$ npm run reset-project'],
    yarn: ['$ yarn run reset-project'],
    pnpm: ['$ pnpm run reset-project'],
    bun: ['$ bun run reset-project'],
  }}
/>

スクリプトは、既存のファイルを削除する代わりに **example** ディレクトリに移動するかどうかを尋ねます。<kbd>Enter</kbd> を押して移動します。

スクリプトが完了すると、**src/app** ディレクトリには 2 つのファイル (**index.tsx** と **\_layout.tsx**) が残ります。スクリプトは、**src** ディレクトリにあった以前のファイル (**components**、**constants**、**hooks** を含む) と **scripts** ディレクトリを **example** ディレクトリに移動します。進めながら独自のディレクトリやコンポーネントファイルを作成していきます。

<Collapsible summary={<><CODE>reset-project</CODE> スクリプトは何をしますか？</>}>

`reset-project` スクリプトは、プロジェクト内の **src/app** ディレクトリ構造をリセットします。プロジェクトの **src** と **scripts** ディレクトリにあった以前のボイラープレートファイルを、**example** という別のサブディレクトリに移動します。**example** はメインアプリの構造の一部ではないため、削除して構いません。スクリプトファイルも **example** に移動するため、`reset-project` をもう一度実行しても動作しません。

</Collapsible>

</Step>

<Step label="4">

## モバイルと web でアプリを実行する

プロジェクトディレクトリで、ターミナルから [開発サーバー](/more/glossary-of-terms/#development-server) を起動するために次のコマンドを実行します。

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

上記のコマンドを実行すると:

1. 開発サーバーが起動し、ターミナルウィンドウ内に QR コードが表示されます。
2. その QR コードをスキャンしてデバイスでアプリを開きます。Android では Expo Go > **Scan QR** オプションを使い、iOS ではデフォルトのカメラアプリを使います。
3. web アプリを実行するには、ターミナルで <kbd>W</kbd> を押します。デフォルトの web ブラウザで web アプリが開きます。

> **info** iOS の実機では、Expo CLI と Expo Go の両方が同じ Expo アカウントでサインインしている場合にのみ、Expo Go はプロジェクトを開きます。コンピュータで `npx expo login` を実行し、同じアカウントで Expo Go にサインインしてください。エラーが解決しない場合は、[Expo Go のサインインが必要](/troubleshooting/expo-go-sign-in-required/)を参照してください。

すべてのプラットフォームで動作すると、アプリは次のようになります。

## index 画面を編集する

{/* vale on */}

**src/app/index.tsx** ファイルは、アプリの画面に表示されるテキストを定義します。これはアプリが最初に表示する画面です。背景とテキストを表示するために、React Native の `<View>` や `<Text>` などのコアコンポーネントを使用します。

これらのコンポーネントに適用されるスタイルは、web で使われる CSS ではなく JavaScript オブジェクトを使います。ただし、これまでに web で CSS を使ったことがあれば、見覚えのあるプロパティが多いはずです。ほとんどの React Native コンポーネントは、JavaScript オブジェクトを値として受け取る `style` プロパティを受け付けます。詳細については [Styling in React Native](https://reactnative.dev/docs/style) を参照してください。

**src/app/index.tsx** 画面を変更しましょう。

1. `styles.container` に `backgroundColor` プロパティを追加し、値を `#25292e` にします。これにより背景色が変わります。
2. `<Text>` のデフォルト値を「Home screen」に置き換えます。
3. `color` プロパティを `#fff` (白) にした `styles.text` オブジェクトを追加します。テキストの色を変えるために、それを `<Text>` の `style` プロパティに渡します。

{/* prettier-ignore */}
```tsx src/app/index.tsx|collapseHeight=340
import { Text, View, StyleSheet } from 'react-native';

export default function Index() {
  return (
    <View style={styles.container}>
      /* @tutinfo `styles.text` を適用します。"Edit src/app/index.tsx to edit this screen." を "Home screen" に置き換えます。 */
      <Text style={styles.text}>Home screen</Text>
      /* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    /* @tutinfo `'#25292e'` の値で `backgroundColor` プロパティを追加します。 */
    backgroundColor: '#25292e',
    /* @end */
    alignItems: 'center',
    justifyContent: 'center',
  },
  /* @tutinfo `color` プロパティを `'#fff'` にした `text` スタイルを追加します。 */
  text: {
    color: '#fff',
  },
  /* @end */
});
```

> React Native は web と同じ色フォーマットを使用します。16 進数トリプレット (これが `#fff` の形式)、`rgba`、`hsl`、および `red`、`green`、`blue`、`peru`、`papayawhip` などの名前付きカラーをサポートします。詳細については [Colors in React Native](https://reactnative.dev/docs/colors) を参照してください。

変更を保存すると、開発サーバーに接続している実行中のアプリに変更が送信され、適用されます。

<Collapsible summary="歯車アイコンとは何ですか？">

歯車アイコンは、Android と iOS プラットフォームの **Tools button** です。これは [開発者メニュー](/debugging/tools/#developer-menu) を開くフローティングショートカットで、アプリのリロードや Fast Refresh の切り替えなどのデバッグ機能を利用できます。開発中にのみ表示され、本番ビルドには含まれません。

このチュートリアルの以降のスクリーンショットでは、このアイコンを非表示にします。非表示にするには:

1. 開発者メニューを開きます。デバイスを振るか、エミュレーター、シミュレーター、または USB 接続したデバイスを使用している場合は、開発サーバーを実行しているターミナルで <kbd>M</kbd> を押します。
2. **Tools button** の項目を見つけて、オフに切り替えます。

非表示にしても開発者メニューが無効になるわけではありません。必要なときは、手順 1 で説明した方法でいつでも開けます。
