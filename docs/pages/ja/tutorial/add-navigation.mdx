## Expo Router の基本

Expo Router は React Native と web アプリ向けのファイルベースのルーティングフレームワークです。画面間のナビゲーションを管理し、複数のプラットフォームで同じコンポーネントを使用できます。始めるにあたって、次の規約を理解しておく必要があります。

- **app ディレクトリ：** ルートとそのレイアウトのみを含む特別なディレクトリです。このディレクトリに追加したファイルは、ネイティブアプリでは画面として、web ではページとして扱われます。デフォルトテンプレートでは **src/app** に配置されています。
- **ルートレイアウト：** **src/app/\_layout.tsx** ファイルです。ヘッダーやタブバーなど、複数のルート間で一貫させたい共有 UI 要素を定義します。
- **ファイル名の規約：** **index.tsx** などの _Index_ ファイル名は、親ディレクトリと一致し、パスセグメントを追加しません。たとえば、**src/app** ディレクトリ内の **index.tsx** は `/` ルートと一致します。
- **ルート** ファイルは React コンポーネントをデフォルト値としてエクスポートします。拡張子は `.js`、`.jsx`、`.ts`、`.tsx` のいずれかを使用できます。
- Android、iOS、web は統一されたナビゲーション構造を共有します。

> 上記のリストで始めるには十分です。すべての機能の一覧については、[Expo Router 紹介](/router/introduction/#key-features) を参照してください。

## スタックに新しい画面を追加する

**src/app** ディレクトリ内に **about.tsx** という名前の新しいファイルを作成しましょう。ユーザーが `/about` ルートに移動したときに、画面名を表示します。

```tsx src/app/about.tsx|collapseHeight=300
import { Text, View, StyleSheet } from 'react-native';

export default function AboutScreen() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>About screen</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    justifyContent: 'center',
    alignItems: 'center',
  },
  text: {
    color: '#fff',
  },
});
```

**src/app/\_layout.tsx** 内で:

1. `<Stack.Screen />` コンポーネントと `options` プロパティを追加して、`/about` ルートのタイトルを更新します。
2. `options` プロパティを追加して、`/index` ルートのタイトルを `Home` に更新します。

{/* prettier-ignore */}
```tsx src/app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    /* @tutinfo `Stack` ナビゲーターの内部に画面をラップします。`/index` ルートに `options` プロパティを追加します。`/about` ルートを追加するため、もう一つの `Stack.Screen` コンポーネントを追加します。 */
    <Stack>
      <Stack.Screen name="index" options={{ title: 'Home' }} />
      <Stack.Screen name="about" options={{ title: 'About' }} />
    </Stack>
    /* @end */
  );
}
```

<Collapsible summary={<><CODE>Stack</CODE> とは何ですか？</>}>

スタックナビゲーターは、アプリ内のさまざまな画面間を移動するための基盤です。Android では、スタックされたルートが現在の画面の上にアニメーションで重なります。iOS では、スタックされたルートが右からアニメーションで表示されます。Expo Router は、新しいルートを追加するためのナビゲーションスタックを作成する `Stack` コンポーネントを提供します。

</Collapsible>

</Step>

## 画面間を移動する

Expo Router の `Link` コンポーネントを使用して、`/index` ルートから `/about` ルートに移動します。これは、指定された `href` プロパティを持つ `<Text>` をレンダリングする React コンポーネントです。

1. **src/app/index.tsx** 内で、`expo-router` から `Link` コンポーネントをインポートします。
2. `<Text>` コンポーネントの後に `Link` コンポーネントを追加し、`href` プロパティに `/about` ルートを渡します。
3. `Link` コンポーネントに `fontSize`、`textDecorationLine`、`color` のスタイルを追加します。`<Text>` コンポーネントと同じプロパティを受け取ります。

{/* prettier-ignore */}
```tsx src/app/index.tsx|collapseHeight=300
import { Text, View, StyleSheet } from 'react-native';
/* @tutinfo `expo-router` から `Link` コンポーネントをインポートします。 */ import { Link } from 'expo-router'; /* @end */

export default function Index() {
  return (
    <View style={styles.container}>
      <Text style={styles.text}>Home screen</Text>
      /* @tutinfo `Text` コンポーネントの後に `Link` コンポーネントを追加し、`href` プロパティに `/about` ルートを渡します。 */
      <Link href="/about" style={styles.button}>
        Go to About screen
      </Link>
      /* @end */
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
    justifyContent: 'center',
  },
  text: {
    color: '#fff',
  },
  /* @tutinfo `Link` コンポーネントに `fontSize`、`textDecorationLine`、`color` のスタイルを追加します。 */
  button: {
    fontSize: 20,
    textDecorationLine: 'underline',
    color: '#fff',
  },
  /* @end */
});
```

アプリの変更を確認しましょう。`Link` をクリックして `/about` ルートに移動します。

## not-found ルートを追加する

ルートが存在しない場合、Expo Router はそのルートに対してデフォルトの画面を表示します。`+not-found` ルートを使用すると、モバイルと web でその画面をカスタムのフォールバック画面に置き換えられます。Expo Router は、このケースを処理するために特別な **+not-found.tsx** ファイルを使用します。

1. **src/app** ディレクトリ内に **+not-found.tsx** という名前の新しいファイルを作成し、`NotFoundScreen` コンポーネントを追加します。
2. `Stack.Screen` の `options` プロパティを追加して、このルートのカスタム画面タイトルを表示します。
3. `Link` コンポーネントを追加して、フォールバックルートである `/` ルートに移動します。

{/* prettier-ignore */}
```tsx src/app/+not-found.tsx
import { View, StyleSheet } from 'react-native';
import { Link, Stack } from 'expo-router';

export default function NotFoundScreen() {
  return (
    <>
      /* @tutinfo `+not-found` ルートのタイトルを更新するため、`options` プロパティを持つ `Stack.Screen` コンポーネントを追加します。 */
      <Stack.Screen options={{ title: 'Oops! Not Found' }} />
      /* @end */
      <View style={styles.container}>
        /* @tutinfo フォールバックルートを追加すると、ユーザーがその画面に遷移できるようになります。ここでは、フォールバックルートは Home 画面です。 */
        <Link href="/" style={styles.button}>
          Go back to Home screen!
        </Link>
        /* @end */
      </View>
    </>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    justifyContent: 'center',
    alignItems: 'center',
  },

  button: {
    fontSize: 20,
    textDecorationLine: 'underline',
    color: '#fff',
  },
});
```

これをテストするには、URL パスを変更しやすい web ブラウザで `http://localhost:8081/123` URL に移動します。アプリには `NotFoundScreen` コンポーネントが表示されるはずです。

## ボトムタブナビゲーターを追加する

この時点で、**src/app** ディレクトリのファイル構造は次のようになっています。

<FileTree
  files={[
    ['src/app/_layout.tsx', 'ルートレイアウト'],
    ['src/app/index.tsx', "ルート '/' に一致"],
    ['src/app/about.tsx', "ルート '/about' に一致"],
    ['src/app/+not-found.tsx', 'すべての 404 ルートに一致'],
  ]}
/>

アプリにボトムタブナビゲーターを追加し、既存の Home と About 画面を再利用してタブレイアウトを作成します。これは、X や Bluesky など、多くのソーシャルメディアアプリで一般的なナビゲーションパターンです。また、ルートレイアウトでスタックナビゲーターを使用することで、`+not-found` ルートが他のネストされたナビゲーターの上に表示されるようにします。

1. **src/app** ディレクトリ内に **(tabs)** サブディレクトリを追加します。この特別なディレクトリは、ルートをグループ化してボトムタブバーに表示するために使われます。
2. ディレクトリ内に **(tabs)/\_layout.tsx** ファイルを作成します。これは、ルートレイアウトとは別のタブレイアウトを定義するために使用されます。
3. 既存の **index.tsx** と **about.tsx** ファイルを **(tabs)** ディレクトリ内に移動します。**src/app** ディレクトリの構造は次のようになります。

<FileTree
  files={[
    ['src/app/_layout.tsx', 'ルートレイアウト'],
    ['src/app/+not-found.tsx', 'すべての 404 ルートに一致'],
    ['src/app/(tabs)/_layout.tsx', 'タブレイアウト'],
    ['src/app/(tabs)/index.tsx', "ルート '/' に一致"],
    ['src/app/(tabs)/about.tsx', "ルート '/about' に一致"],
  ]}
/>

ルートレイアウトファイルを更新して、`(tabs)` ルートを追加します。

{/* prettier-ignore */}
```tsx src/app/_layout.tsx
import { Stack } from 'expo-router';

export default function RootLayout() {
  return (
    <Stack>
      /* @tutinfo これは、特に Root レイアウトが親のスタックナビゲーターで構成されている場合に、タブナビゲーターをスタックナビゲーターの内部にネストする方法です。また、`(tabs)` ルートのスタックヘッダーを非表示にするため、`headerShown` オプションを `false` に設定しています。そうしないと、タブの上にルート名 `(tabs)` を表示するヘッダーが表示されてしまいます。 */
      <Stack.Screen name="(tabs)" options={{ headerShown: false }} />
      /* @end */
    </Stack>
  );
}
```

**(tabs)/\_layout.tsx** 内に `NativeTabs` コンポーネントを追加して、ボトムタブレイアウトを定義します。[ネイティブタブ](/router/advanced/native-tabs/)は、Android と iOS でプラットフォームのネイティブなタブバーを使用します。

{/* prettier-ignore */}
```tsx src/app/(tabs)/_layout.tsx
import { NativeTabs } from 'expo-router/native-tabs';

export default function TabLayout() {
  return (
    <NativeTabs>
      /* @tutinfo 各 `NativeTabs.Trigger` は、`name` プロパティで指定したルートのタブを追加します。`NativeTabs.Trigger.Label` はタブのテキストを設定します。 */
      <NativeTabs.Trigger name="index">
        <NativeTabs.Trigger.Label>Home</NativeTabs.Trigger.Label>
      </NativeTabs.Trigger>
      <NativeTabs.Trigger name="about">
        <NativeTabs.Trigger.Label>About</NativeTabs.Trigger.Label>
      </NativeTabs.Trigger>
      /* @end */
    </NativeTabs>
  );
}
```

ネイティブタブは画面にヘッダーを追加しないため、Home と About 画面にはヘッダーが表示されなくなります。web では、タブはページ上部にラベルの一覧として表示されます。

新しいボトムタブが表示されたアプリを確認してみましょう。

## ボトムタブナビゲーターの外観を更新する

現時点では、ボトムタブナビゲーターはアプリのスタイルと合っていません。たとえば、タブにアイコンが表示されず、タブバーの色がアプリの背景色と一致していません。

**src/app/(tabs)/\_layout.tsx** ファイルを修正して、タブバーアイコンを追加します。

1. 各 `NativeTabs.Trigger` の内部に `NativeTabs.Trigger.Icon` コンポーネントを追加します。`md` プロパティは Android 用の [Material Symbols](https://fonts.google.com/icons) の名前を受け取ります。`sf` プロパティは iOS 用の [SF Symbols](https://developer.apple.com/sf-symbols/) の名前を受け取ります。
2. `default` と `selected` のキーを持つオブジェクトを `sf` プロパティに渡します。iOS では、タブがアクティブのときに `selected` のアイコンが表示されます。
3. `NativeTabs` コンポーネントに `tintColor` プロパティを追加し、値を `#ffd33d` に設定します。これにより、アクティブなタブのアイコンとラベルの色が変わります。

{/* prettier-ignore */}
```tsx src/app/(tabs)/_layout.tsx
import { NativeTabs } from 'expo-router/native-tabs';

export default function TabLayout() {
  return (
    <NativeTabs
      /* @tutinfo `tintColor` プロパティは、アクティブなタブのアイコンとラベルの色を変更します。この色はアプリの後の部分でも使用します。 */
      tintColor="#ffd33d"
      /* @end */
    >
      <NativeTabs.Trigger name="index">
        <NativeTabs.Trigger.Label>Home</NativeTabs.Trigger.Label>
        /* @tutinfo `md` プロパティは Android のアイコンを設定し、`sf` プロパティは iOS のアイコンを設定します。 */
        <NativeTabs.Trigger.Icon
          sf={{ default: 'house', selected: 'house.fill' }}
          md="home"
        />
        /* @end */
      </NativeTabs.Trigger>
      <NativeTabs.Trigger name="about">
        <NativeTabs.Trigger.Label>About</NativeTabs.Trigger.Label>
        /* @tutinfo */
        <NativeTabs.Trigger.Icon
          sf={{ default: 'info.circle', selected: 'info.circle.fill' }}
          md="info"
        />
        /* @end */
      </NativeTabs.Trigger>
    </NativeTabs>
  );
}
```

アイコンにはインストール手順は必要ありません。Android では、デフォルトテンプレートに含まれる `expo-symbols` ライブラリが Material Symbols を提供します。iOS では、SF Symbols はシステムの一部です。web では、タブにはラベルのみが表示されます。

`backgroundColor` プロパティを使って、タブバーの背景色も変更しましょう。

```tsx src/app/(tabs)/_layout.tsx
<NativeTabs tintColor="#ffd33d" backgroundColor="#25292e">
```

`backgroundColor` プロパティは、Android と web でタブバーに `#25292e` を適用します。iOS 26 以降では、`backgroundColor` は効果がありません。タブバーは Liquid Glass を使用し、デバイスのライトまたはダークの外観に従います。

これでアプリにカスタムボトムタブナビゲーターが追加されました。

## Android のリップルとインジケーターの色を更新する

Android では、タブバーはまだデフォルトの Material 3 テーマの 2 つの色を使用しています。タブを押すと、リップルエフェクトが表示されます。アクティブなタブには、アイコンの背後にインジケーターが表示されます。どちらの色もアプリのカラーパレットと一致していません。

**src/app/(tabs)/\_layout.tsx** の `NativeTabs` コンポーネントに、`indicatorColor` と `rippleColor` プロパティを追加します。

{/* prettier-ignore */}
```tsx src/app/(tabs)/_layout.tsx
<NativeTabs
  tintColor="#ffd33d"
  backgroundColor="#25292e"
  /* @tutinfo どちらの色も、アクティブなタブの黄色 `#ffd33d` に透明度を加えたものです。 */
  indicatorColor="rgba(255, 211, 61, 0.2)"
  rippleColor="rgba(255, 211, 61, 0.3)"
  /* @end */
>
```

上記のコードでは:

- `indicatorColor` は、Android ではアクティブなタブの背後にあるインジケーターの色を設定し、web ではアクティブなタブの背景色を設定します。
- `rippleColor` は、Android でユーザーがタブを押したときに表示されるリップルエフェクトの色を設定します。

これで、リップルとインジケーターがアクティブなタブの黄色を使用するようになりました。
