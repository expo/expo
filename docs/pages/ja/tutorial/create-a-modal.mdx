モーダルは、アプリの他のコンテンツの上にコンテンツを表示します。一般的に、モーダルはユーザーの注意を重要な情報に向けたり、アクションを促したりするために使用されます。ボトムシートは、画面下からスライドして表示されるモーダルの一種です。

この章では、Expo UI の [`BottomSheet`](/versions/latest/sdk/ui/universal/bottomsheet/) コンポーネントを使って絵文字ピッカーを作成します。Android と iOS では、プラットフォームのネイティブのボトムシートを表示します。web では、ページ下部にシートを表示します。

## ボタンを表示するための状態変数を宣言する

ボトムシートを実装する前に、新しいボタンを 3 つ追加します。これらのボタンは、ユーザーがメディアライブラリから画像を選択したり、プレースホルダー画像を使ったりした後に表示されます。ボタンのうちの 1 つが絵文字ピッカーを開きます。

**src/app/(tabs)/index.tsx** で:

1. 絵文字ピッカーを開くボタンや他のオプションの表示・非表示を切り替えるために、ブール値の状態変数 `showAppOptions` を宣言します。アプリ画面の読み込み時には `false` にして、画像を選択する前にはオプションを表示しないようにします。ユーザーが画像を選択したり、プレースホルダー画像を使ったりすると、`true` に設定します。
2. `pickImageAsync()` 関数を更新して、ユーザーが画像を選択した後に `showAppOptions` の値を `true` に設定します。
3. テーマが設定されていないボタンの `onPress` プロパティで、`alert()` を `showAppOptions` を `true` に設定する関数に置き換えます。

```tsx src/app/(tabs)/index.tsx
import { useState } from 'react';
import { Platform, View, StyleSheet } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import * as ImagePicker from 'expo-image-picker';

import Button from '@/components/button';
import ImageViewer from '@/components/image-viewer';

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  const [selectedImage, setSelectedImage] = useState<string | undefined>(undefined);
  /* @tutinfo `Index` コンポーネント内に state 変数を作成します。 */
  const [showAppOptions, setShowAppOptions] = useState<boolean>(false);
  /* @end */

  const pickImageAsync = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      quality: 1,
    });

    if (!result.canceled) {
      setSelectedImage(result.assets[0].uri);
      /* @tutinfo 画像を選択した後、app options を true に設定します。 */
      setShowAppOptions(true);
      /* @end */
    } else {
      alert('You did not select any image.');
    }
  };

  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        <ImageViewer imgSource={PlaceholderImage} selectedImage={selectedImage} />
      </View>
      /* @tutinfo `showAppOptions` の値に基づいてボタンが表示されます。また、既存のボタンを三項演算子のブロック内に移動します。 */
      {showAppOptions ? (
        <View />
      /* @end */
      ) : (
        <View style={styles.footerContainer}>
          <Button theme="primary" label="Choose a photo" onPress={pickImageAsync} />
          /* @tutinfo `alert()` を、`showAppOptions` を `true` に設定する関数に置き換えます。 */
          <Button label="Use this photo" onPress={() => setShowAppOptions(true)} />
          /* @end */
        </View>
      /* @tutinfo */)}/* @end */
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  footerContainer: {
    flex: 1 / 3,
    alignItems: 'center',
  },
});
```

上記のスニペットでは、`showAppOptions` の値に応じて `Button` コンポーネントをレンダリングし、ボタンを三項演算子ブロックの中に移動しています。`showAppOptions` の値が `true` の場合は、空の `<View>` コンポーネントをレンダリングします。この状態については次のステップで対応します。

上記のコードが何をしているのか確認しましょう。

- Android では、`FloatingActionButton` が Material 3 のフローティングアクションボタンを表示します。`size` と `clip` モディファイアで 84 dp の円形にし、`Icon` が `@expo/material-symbols` の **add.xml** アイコンを表示します。

他の 2 つのボタンは、テキストラベルの上にアイコンを表示します。**src/components** ディレクトリ内に、アイコンボタン用の 3 つのファイルを作成します。このコンポーネントは 3 つのプロパティを受け取ります。

- `onPress`: ユーザーがボタンを押したときに実行される関数です。

## ボトムシートで絵文字ピッカーを作成する

ボトムシートでは、利用可能な絵文字のリストからユーザーが絵文字を選択できます。**src/components** ディレクトリ内に **emoji-picker.tsx** ファイルを作成します。このコンポーネントは 3 つのプロパティを受け取ります。

- `isVisible`: ボトムシートを表示するかどうかを決定するブール値です。
- `onClose`: ボトムシートを閉じる関数です。
- `children`: 後で絵文字のリストを表示するために使用します。

{/* prettier-ignore */}
```tsx src/components/emoji-picker.tsx
import { PropsWithChildren } from 'react';
import { StyleSheet, Text, View } from 'react-native';
/* @tutinfo Expo UI から `BottomSheet` と `RNHostView` をインポートします。 */
import { BottomSheet, RNHostView } from '@expo/ui';
/* @end */

type Props = PropsWithChildren<{
  isVisible: boolean;
  onClose: () => void;
}>;

export default function EmojiPicker({ isVisible, children, onClose }: Props) {
  return (
    <BottomSheet
      isPresented={isVisible}
      onDismiss={onClose}
      snapPoints={/* @tutinfo ボトムシートを画面の高さの約半分で開きます。 */['half']/* @end */}
      containerColor="#25292e">
      /* @tutinfo `RNHostView` は、ボトムシート内に React Native のビューを表示します。 */
      <RNHostView>
        <View>
          <Text style={styles.title}>Choose a sticker</Text>
          {children}
        </View>
      </RNHostView>
      /* @end */
    </BottomSheet>
  );
}

const styles = StyleSheet.create({
  title: {
    color: '#fff',
    fontSize: 16,
    marginBottom: 20,
  },
});
```

上記のコードが何をしているのか確認しましょう。

- `BottomSheet` コンポーネントは、デフォルトテンプレートにすでに含まれている `@expo/ui` から提供されます。Android では Material 3 のボトムシートを表示します。iOS では SwiftUI のシートを表示します。web では、ページ下部にシートを表示します。
- `isPresented` プロパティは `isVisible` の値を受け取り、ボトムシートが開いているか閉じているかを制御します。
- `onDismiss` プロパティは、ユーザーがボトムシートを閉じたときに `onClose` を呼び出します。ユーザーは、ボトムシートを下にスワイプするか、ボトムシートの外側をタップして閉じることができます。Android では、戻るボタンでも閉じます。web では、<kbd>Esc</kbd> キーでも閉じます。
- `snapPoints` プロパティは、ボトムシートが停止できる高さを設定します。`'half'` の値は、画面の高さの約半分でボトムシートを開きます。
- `containerColor` プロパティは、アプリの背景に合わせてボトムシートの背景色を設定します。
- `RNHostView` コンポーネントは、`<View>` や `<Text>` などの React Native のビューをボトムシート内に表示します。

<Collapsible summary={<><CODE>RNHostView</CODE> とは何ですか？</>}>

Android と iOS では、`BottomSheet` は Jetpack Compose と SwiftUI のネイティブビューです。その中に React Native のビューを表示するには、それらを `RNHostView` でラップします。これは `Host` と逆方向に機能します。`Host` は、[第 3 章](/ja/tutorial/build-a-screen/#expo-ui-でネイティブボタンを使用する) で React Native のビュー内に Expo UI コンポーネントを表示するために使用しました。`BottomSheet` は独自の `Host` を作成するため、`Host` でラップする必要はありません。詳細については、[`RNHostView`](/versions/latest/sdk/ui/universal/rnhostview/) を参照してください。

</Collapsible>

それでは、**src/app/(tabs)/index.tsx** を変更しましょう。

1. `<EmojiPicker>` コンポーネントをインポートします。
2. `useState` フックで `isModalVisible` 状態変数を作成します。デフォルト値は `false` で、ユーザーがボタンを押すまでボトムシートは非表示のままです。

## 絵文字のリストを表示する

ボトムシートのコンテンツに絵文字のグリッドを追加しましょう。これには React Native の [`<FlatList>`](https://reactnative.dev/docs/flatlist) コンポーネントを使用します。

**src/components** ディレクトリ内に **emoji-list.tsx** ファイルを作成し、次のコードを追加します。

{/* prettier-ignore */}
```tsx src/components/emoji-list.tsx
import { FlatList, Pressable, StyleSheet } from 'react-native';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  onSelect: (image: ImageSource) => void;
  onCloseModal: () => void;
};

/* @tutinfo `assets/images` ディレクトリにある絵文字画像です。 */
const emoji: ImageSource[] = [
  require('@/assets/images/emoji1.png'),
  require('@/assets/images/emoji2.png'),
  require('@/assets/images/emoji3.png'),
  require('@/assets/images/emoji4.png'),
  require('@/assets/images/emoji5.png'),
  require('@/assets/images/emoji6.png'),
];
/* @end */

export default function EmojiList({ onSelect, onCloseModal }: Props) {
  return (
    <FlatList
      data={emoji}
      numColumns={/* @tutinfo リストを 3 列のグリッドとして表示します。 */3/* @end */}
      columnWrapperStyle={styles.row}
      renderItem={({ item }) => (
        <Pressable
          onPress={() => {
            onSelect(item);
            onCloseModal();
          }}>
          <Image source={item} style={styles.image} />
        </Pressable>
      )}
    />
  );
}

const styles = StyleSheet.create({
  row: {
    justifyContent: 'space-around',
    marginBottom: 20,
  },
  image: {
    width: 100,
    height: 100,
  },
});
```

上記のコードが何をしているのか確認しましょう。

- `emoji` 配列は絵文字画像を保持します。値が変わることはないため、コンポーネントの外側に置いています。
- `<FlatList>` コンポーネントは、`data` プロパティの値として `emoji` 配列を受け取ります。`renderItem` プロパティは `data` から各アイテムを受け取り、`<Pressable>` でラップした `Image` コンポーネントを返します。ユーザーが絵文字を押すと、`onSelect` がその絵文字を受け取り、`onCloseModal` がボトムシートを閉じます。
- `numColumns` プロパティは、リストを 3 列のグリッドとして表示します。`columnWrapperStyle` プロパティは、グリッドの各行のスタイルを設定します。
