## 画像を表示する

アプリ内で画像を表示するために `expo-image` ライブラリを使用します。このライブラリは、画像を読み込んで描画するためのクロスプラットフォームな `<Image>` コンポーネントを提供します。使用しているデフォルトのプロジェクトテンプレートにすでに含まれています。

Image コンポーネントは画像のソースを値として受け取ります。ソースには [静的アセット](https://reactnative.dev/docs/images#static-image-resources) または URL を指定できます。たとえば、**assets/images** ディレクトリから読み込むソースは静的アセットです。また、`uri` プロパティを使って [ネットワーク](https://reactnative.dev/docs/images#network-images) から取得することもできます。

<ContentSpotlight
  alt="チュートリアルでプレースホルダーとして使用する背景画像。"
  src="/static/images/tutorial/background-image.webp"
  className="max-w-[250px]"
/>

**src/app/(tabs)/index.tsx** ファイルで Image コンポーネントを使うには:

1. `expo-image` ライブラリから `Image` をインポートします。
2. **assets/images/background-image.png** を `Image` コンポーネントの `source` プロパティとして使用するために、`PlaceholderImage` 変数を作成します。
3. 外側の `View` を `react-native-safe-area-context` の `SafeAreaView` に置き換えます。ネイティブタブはヘッダーを追加しないため、`SafeAreaView` を使うと Android と iOS で画面のコンテンツがステータスバーの下に配置されます。デフォルトテンプレートにはこのライブラリが含まれています。
4. [`Platform.select()`](https://reactnative.dev/docs/platform#select) を使って、画像コンテナに `paddingTop` を追加します。web ではタブリストがページの上部に配置されるため、画像にはより多くのスペースが必要です。

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=380
import { Platform, View, StyleSheet } from 'react-native';
/* @tutinfo `Image` コンポーネントをインポートします。 */ import { Image } from 'expo-image'; /* @end */
/* @tutinfo `SafeAreaView` コンポーネントをインポートします。外側の `View` をこのコンポーネントに置き換えます。 */ import { SafeAreaView } from 'react-native-safe-area-context'; /* @end */

/* @tutinfo "assets/images/" ディレクトリから画像をインポートします。この画像は静的リソースであるため、`require` を使用して参照する必要があります。 */
const PlaceholderImage = require('@/assets/images/background-image.png');
/* @end */

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      /* @tutinfo `Image` コンポーネントをコンテナの内部にラップします。また、プレースホルダー画像を表示するため、画像コンポーネントを追加します。 */
      <View style={styles.imageContainer}>
        <Image source={PlaceholderImage} style={styles.image} />
      </View>
      /* @end */
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    /* @tutinfo `justifyContent` プロパティを削除するため、コンテナのスタイルを変更します。 */
    alignItems: 'center',
    /* @end */
  },
  /* @tutinfo 画像コンテナと画像のスタイルを追加します。`Platform.select()` は Android と iOS では `20` を、web では `96` を返します。 */
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
  image: {
    width: 320,
    height: 440,
    borderRadius: 18,
  },
  /* @end */
});
```

## コンポーネントをファイルに分割する

この画面にコンポーネントを追加していく中で、コードを複数のファイルに分割しましょう。チュートリアル全体を通して、カスタムコンポーネントの作成には components ディレクトリを使用します。

1. **src** 内に **components** ディレクトリを作成し、その中に **image-viewer.tsx** ファイルを作成します。
2. 画像を表示するコードと `image` スタイルをこのファイルに移動します。

{/* prettier-ignore */}
```tsx src/components/image-viewer.tsx|collapseHeight=280
import { StyleSheet } from 'react-native';
import { Image, type ImageSource } from 'expo-image';

type Props = {
  /* @tutinfo `expo-image` の `ImageSource` 型は、`source` プロパティが受け付ける値を表します。 */imgSource: ImageSource;/* @end */
};

export default function ImageViewer({ imgSource }: Props) {
  return <Image source={imgSource} style={styles.image} />;
}

const styles = StyleSheet.create({
  image: {
    width: 320,
    height: 440,
    borderRadius: 18,
  },
});
```

> **info** **ImageViewer** はカスタムコンポーネントであるため、**src/app** ディレクトリではなく別のディレクトリに配置しています。**src/app** ディレクトリ内のファイルはすべて、レイアウトファイルかルートファイルのいずれかです。詳細については [ナビゲーション以外のコンポーネントは src/app ディレクトリの外に置く](/router/basics/core-concepts/#6-non-navigation-components-live-outside-the-srcapp-directory) を参照してください。

`ImageViewer` をインポートして、**src/app/(tabs)/index.tsx** で使用します。

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx|collapseHeight=320
import { Platform, StyleSheet, View } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

/* @tutinfo */import ImageViewer from '@/components/image-viewer'; /* @end */

const PlaceholderImage = require('@/assets/images/background-image.png');

export default function Index() {
  return (
    <SafeAreaView style={styles.container}>
      <View style={styles.imageContainer}>
        /* @tutinfo `Image` コンポーネントを `ImageViewer` に置き換えます。 */
        <ImageViewer imgSource={PlaceholderImage} />
        /* @end */
      </View>
    </SafeAreaView>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,
    paddingTop: Platform.select({ web: 96, default: 20 }),
  },
});
```

## Pressable を使ってボタンを作成する

React Native にはタッチイベントを扱うためのコンポーネントがいくつかありますが、柔軟性が高い [`<Pressable>`](https://reactnative.dev/docs/pressable) が推奨されます。シングルタップ、長押し、押下時と解放時で別々のイベントの発火など、さまざまな操作を検出できます。

デザイン上、作成すべきボタンは 2 つあります。それぞれスタイルとラベルが異なります。まずは、これらのボタンの再利用可能なコンポーネントを作成しましょう。**src/components** ディレクトリ内に **button.tsx** ファイルを作成し、次のコードを記述します。

{/* prettier-ignore */}
```tsx src/components/button.tsx|collapseHeight=280
import { StyleSheet, View, Pressable, Text } from 'react-native';

type Props = {
  label: string;
  /* @tutinfo ボタンをレンダリングする画面が、ボタンが押されるたびに実行する関数を渡します。 */onPress?: () => void;/* @end */
};

export default function Button({ label, onPress }: Props) {
  return (
    <View style={styles.buttonContainer}>
      <Pressable style={styles.button} onPress={onPress}>
        <Text style={styles.buttonLabel}>{label}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
  button: {
    height: 48,
    paddingHorizontal: 20,
    borderRadius: 24,
    alignItems: 'center',
    justifyContent: 'center',
    flexDirection: 'row',
    gap: 8,
  },
  buttonLabel: {
    color: '#fff',
    fontSize: 16,
  },
});
```

`onPress` プロパティを使うと、ユーザーがボタンを押したときの動作を画面側で決められます。このコンポーネントを **src/app/(tabs)/index.tsx** ファイルにインポートしましょう。各ボタンに、`alert()` を呼び出す `onPress` 関数を渡します。次に、ボタンを囲む `<View>` のスタイルを追加します。

{/* prettier-ignore */}
```tsx src/app/(tabs)/index.tsx

import { SafeAreaView } from 'react-native-safe-area-context';

/* @tutinfo */import Button from '@/components/button'; /* @end */

  return (

      /* @tutinfo 再利用可能な `Button` コンポーネントを使って 2 つのボタンを作成し、`View` コンポーネント内にカプセル化します。 */
      <View style={styles.footerContainer}>
        <Button label="Choose a photo" onPress={() => alert('You pressed a button.')} />
        <Button label="Use this photo" onPress={() => alert('You pressed a button.')} />

}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#25292e',
    alignItems: 'center',
  },
  imageContainer: {
    flex: 1,

  },
  /* @tutinfo 以下のスタイルを追加します。 */

    flex: 1 / 3,
    alignItems: 'center',

```

## 再利用可能なボタンコンポーネントを強化する

「Choose a photo」ボタンには「Use this photo」ボタンとは異なるスタイルが必要です。`primary` テーマを適用するために、`theme` プロパティを追加しましょう。このボタンにはラベルの前にアイコンも表示します。アイコンの表示には [`expo-symbols`](/versions/latest/sdk/symbols/) の `SymbolView` コンポーネントを使用します。Android と web では、`SymbolView` は [Material Symbols](https://fonts.google.com/icons) のアイコンを表示します。iOS では、[SF Symbols](https://developer.apple.com/sf-symbols/) のアイコンを表示します。デフォルトテンプレートにはすでに `expo-symbols` が含まれています。

**src/components/button.tsx** を修正して、次のコードスニペットを追加します。

{/* prettier-ignore */}
```tsx src/components/button.tsx
import { StyleSheet, View, Pressable, Text } from 'react-native';
/* @tutinfo SymbolView をインポートします。 */import { SymbolView } from 'expo-symbols';/* @end */

type Props = {
  label: string;
  /* @tutinfo theme プロパティを追加します。 */theme?: 'primary';/* @end */
  onPress?: () => void;
};

export default function Button({ label, /* @tutinfo ボタンのバリアントを判定するため、`theme` プロパティを使います。 */theme/* @end */, onPress }: Props) {
  /* @tutinfo primary テーマのボタンを条件付きでレンダリングします。 */
  if (theme === 'primary') {
  /* @end */
  /* @tutinfo */
    return (
      <View style={styles.buttonContainer}>
        <Pressable style={[styles.button, styles.primaryButton]} onPress={onPress}>
          <SymbolView
            name={{ ios: 'photo', android: 'image', web: 'image' }}
            size={18}
            tintColor="#25292e"
          />
          <Text style={[styles.buttonLabel, { color: '#25292e' }]}>{label}</Text>
        </Pressable>
      </View>
    );
  /* @end */
  /* @tutinfo */
  }
  /* @end */

  return (
    <View style={styles.buttonContainer}>
      <Pressable style={styles.button} onPress={onPress}>
        <Text style={styles.buttonLabel}>{label}</Text>
      </Pressable>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
  button: {
    height: 48,
    paddingHorizontal: 20,
    borderRadius: 24,
    alignItems: 'center',
    justifyContent: 'center',
    flexDirection: 'row',
    gap: 8,
  },
  /* @tutinfo primary テーマのスタイルを追加します。 */
  primaryButton: {
    backgroundColor: '#ffd33d',
  },
  /* @end */
  buttonLabel: {
    color: '#fff',
    fontSize: 16,
  },
});
```

上記のコードが何をしているのか確認しましょう。

- primary テーマのボタンは、`<Pressable>` の `style` プロパティに配列を渡します。React Native はスタイルを順番に適用するため、`styles.primaryButton` の `backgroundColor` は primary ボタンにのみ適用されます。
- primary ボタンのラベルは **インラインスタイル** を使用します。インラインスタイルとは、`style` プロパティに直接渡すオブジェクトです。これはラベルの色を `#25292e` に変更し、`styles.buttonLabel` の `color` を上書きします。
- `SymbolView` の `name` プロパティは、プラットフォームごとのアイコン名を受け取ります。Android と web では `image`、iOS では `photo` です。

次に、**src/app/(tabs)/index.tsx** ファイルを修正して、1 つ目のボタンに `theme="primary"` プロパティを設定します。

## Expo UI でネイティブボタンを使用する

現在のボタンは React Native のコンポーネントを使用しているため、どのプラットフォームでも同じ見た目になります。[Expo UI](/versions/latest/sdk/ui/) はネイティブコンポーネントを提供します。Android では Jetpack Compose のビュー、iOS では SwiftUI のビューです。デフォルトテンプレートにはすでに Expo UI（`@expo/ui`）が含まれています。Expo UI は Expo Go で動作します。

Android と iOS のボタンをネイティブボタンに置き換え、web では React Native のボタンをそのまま使いましょう。そのために、プラットフォーム固有の拡張子を使用します。**button.tsx** と同じ場所に **button.android.tsx** と **button.ios.tsx** があると、`@/components/button` をインポートしたときに、Metro は現在のプラットフォーム用のファイルを使用します。web では引き続き **button.tsx** が使われます。詳細については [プラットフォーム固有の拡張子](/router/advanced/platform-specific-modules/#platform-specific-extensions) を参照してください。

Android のボタンには、[`@expo/material-symbols`](https://www.npmjs.com/package/@expo/material-symbols) のアイコンを表示します。これは Jetpack Compose 向けの Material Symbols アイコンのセットです。インストールするには、ターミナルで <kbd>Ctrl</kbd> + <kbd>C</kbd> を押して開発サーバーを停止してから、次のコマンドを実行します。

<Terminal
  cmd={{
    npm: ['$ npx expo install @expo/material-symbols'],
    yarn: ['$ yarn expo install @expo/material-symbols'],
    pnpm: ['$ pnpm expo install @expo/material-symbols'],
    bun: ['$ bun expo install @expo/material-symbols'],

/>

2 つの新しいファイルを作成するまで、開発サーバーは停止したままにしておきます。サーバーの実行中にファイルを追加すると、Metro が **button.tsx** を使い続けることがあります。その場合は、サーバーを再起動してください。

**src/components** ディレクトリ内に **button.android.tsx** ファイルを作成します。

{/* prettier-ignore */}
```tsx src/components/button.android.tsx
import { StyleSheet, View } from 'react-native';
/* @tutinfo Expo UI から Jetpack Compose のコンポーネントをインポートします。 */import { Host, Button as ComposeButton, TextButton, Icon, Row, Text } from '@expo/ui/jetpack-compose';/* @end */

type Props = {
  label: string;
  theme?: 'primary';
  onPress?: () => void;
};

export default function Button({ label, theme, onPress }: Props) {
  if (theme === 'primary') {
    return (
      <View style={styles.buttonContainer}>
        /* @tutinfo `colors` プロパティは、ボタンのコンテナとコンテンツの色を設定します。`Row` はアイコンとラベルを横に並べ、その間に 8 dp のスペースを空けます。 */
        <Host matchContents>
          <ComposeButton
            onClick={onPress}
            colors={{ containerColor: '#ffd33d', contentColor: '#25292e' }}>
            <Row verticalAlignment="center" horizontalArrangement={{ spacedBy: 8 }}>
              <Icon source={require('@expo/material-symbols/image.xml')} size={18} tint="#25292e" />
              <Text color="#25292e">{label}</Text>
            </Row>
          </ComposeButton>
        </Host>
        /* @end */
      </View>
    );
  }

  return (
    <View style={styles.buttonContainer}>
      <Host matchContents>
        /* @tutinfo `TextButton` は背景のないボタンを表示します。 */
        <TextButton onClick={onPress} colors={{ contentColor: '#fff' }}>
          <Text color="#fff">{label}</Text>
        </TextButton>
        /* @end */
      </Host>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

<Collapsible summary={<><CODE>Host</CODE> とは何ですか？</>}>

`Host` は React Native と Expo UI をつなぐブリッジです。Android の Jetpack Compose コンポーネントと iOS の SwiftUI コンポーネントは、`Host` の内側でのみレンダリングされます。`matchContents` プロパティは、`Host` のサイズをコンテンツに合わせます。ここでのコンテンツはボタンです。詳細については、[Jetpack Compose](/versions/latest/sdk/ui/jetpack-compose/host/) と [SwiftUI](/versions/latest/sdk/ui/swift-ui/host/) の `Host` を参照してください。

</Collapsible>

次に、**src/components** ディレクトリ内に **button.ios.tsx** ファイルを作成します。

{/* prettier-ignore */}
```tsx src/components/button.ios.tsx
import { StyleSheet, View } from 'react-native';
/* @tutinfo Expo UI から SwiftUI のコンポーネントとモディファイアをインポートします。 */
import { Host, Button as SwiftUIButton } from '@expo/ui/swift-ui';
import { buttonStyle, controlSize, foregroundStyle, tint } from '@expo/ui/swift-ui/modifiers';
/* @end */

type Props = {
  label: string;
  theme?: 'primary';
  onPress?: () => void;
};

export default function Button({ label, theme, onPress }: Props) {
  if (theme === 'primary') {
    return (
      <View style={styles.buttonContainer}>
        <Host matchContents>
          /* @tutinfo `systemImage` はラベルの前に SF Symbols のアイコンを表示します。モディファイアはボタンのスタイルを変更します。`tint` はボタンの色を設定し、`foregroundStyle` はアイコンとラベルの色を設定します。 */
          <SwiftUIButton
            label={label}
            systemImage="photo"
            onPress={onPress}
            modifiers={[
              buttonStyle('borderedProminent'),
              controlSize('large'),
              tint('#ffd33d'),
              foregroundStyle('#25292e'),
            ]}
          />
          /* @end */
        </Host>
      </View>
    );
  }

  return (
    <View style={styles.buttonContainer}>
      <Host matchContents>
        /* @tutinfo `borderless` は背景のないボタンを表示します。 */
        <SwiftUIButton
          label={label}
          onPress={onPress}
          modifiers={[buttonStyle('borderless'), controlSize('large'), foregroundStyle('#fff')]}
        />
        /* @end */
      </Host>
    </View>
  );
}

const styles = StyleSheet.create({
  buttonContainer: {
    width: 320,
    height: 68,
    alignItems: 'center',
    justifyContent: 'center',
  },
});
```

<Collapsible summary="モディファイアとは何ですか？">

モディファイアは、スタイル、サイズ、色など、Expo UI コンポーネントの見た目と動作をカスタマイズします。Jetpack Compose では `@expo/ui/jetpack-compose/modifiers` から、SwiftUI では `@expo/ui/swift-ui/modifiers` からインポートします。次に、**button.ios.tsx** のように、コンポーネントの `modifiers` プロパティに配列として渡します。詳細については、[Jetpack Compose](/versions/latest/sdk/ui/jetpack-compose/modifiers/) と [SwiftUI](/versions/latest/sdk/ui/swift-ui/modifiers/) のモディファイアを参照してください。

</Collapsible>

どちらのファイルも **button.tsx** と同じプロパティを持つため、**src/app/(tabs)/index.tsx** を変更する必要はありません。**src/components** ディレクトリには、3 つのバージョンのボタンが含まれるようになりました。

<Collapsible summary={<>なぜ <CODE>button.tsx</CODE> を残すのですか？</>}>

**button.web.tsx** ファイルがないため、web では **button.tsx** が使われます。また、TypeScript は `@/components/button` の型を **button.tsx** から読み取ります。そのため、3 つのファイルはすべて同じプロパティを受け付ける必要があります。

</Collapsible>
