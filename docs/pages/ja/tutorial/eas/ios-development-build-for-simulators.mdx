この章では、EAS Build を使って iOS Simulator で動作する開発ビルドを作成します。

iOS Simulator 向けの開発ビルドは **.app** 形式で生成され、iOS 実機向けとは異なります。

## eas.json にシミュレーター用のビルドプロファイルを作成する

**eas.json** に `ios-simulator` という新しいビルドプロファイルを追加し、[`ios.simulator`](/eas/json/#simulator) プロパティを `true` に設定します。

{/* prettier-ignore */}
```json eas.json
{
  "build": {
    "development": {
      /* @hide ... */ /* @end */
    },
    /* @info `simulator` プロパティは iOS Simulator ビルドに必須です。 */
    "ios-simulator": {
      "ios": {
        "simulator": true
      }
    }
    /* @end */
  }
}
```

開発ビルドでは、プロファイルに `developmentClient` と `distribution` プロパティが定義されている必要があります。重複を避けるため、`development` プロファイルのプロパティを継承しましょう。

```json eas.json
{
  "ios-simulator": {
    /* @info `extends` キーワードは `development` プロファイルのプロパティを継承します。 */
    "extends": "development",
    /* @end */
    "ios": {
      "simulator": true
    }
  }
}
```

## iOS Simulator 向けの開発ビルド

<Step label="1">

### 作成する

プラットフォームに `ios`、ビルドプロファイルに `ios-simulator` を指定して `eas build` コマンドを実行します。

<Terminal cmd={['$ eas build --platform ios --profile ios-simulator']} />

初めてビルドを作成するとき、このコマンドは次の質問を表示します。

- **What would you like your iOS bundle identifier to be?**（iOS のバンドル識別子を何にしますか？）<kbd>Return</kbd> を押して、表示されるデフォルト値を選びます。これにより **app.json** に [`ios.bundleIdentifier`](/versions/latest/config/app/#bundleidentifier) が追加されます。
- **iOS app only uses standard/exempt encryption?**（この iOS アプリは標準的な、または適用除外の暗号化のみを使いますか？）<kbd>Y</kbd> を押してデフォルト値を選びます。このアプリは暗号化を使っていないため、**Info.plist** ファイルの `ITSAppUsesNonExemptEncryption` が `NO` に設定され、TestFlight や Apple App Store にリリースする際のコンプライアンスチェックが処理されます。自分のアプリをリリースする際に暗号化を使っている場合は、`N` を選べば次回からこの質問を省略できます。

質問に答えると EAS Build がキューに入り、EAS CLI が EAS ダッシュボードでビルドの詳細と進捗を確認できるリンクを表示します。

<ContentSpotlight
  alt="iOS Simulator build details page"
  src="/static/images/tutorial/eas/ios-sim-build.png"
  className="max-w-[800px]"
/>

<Collapsible summary="ビルド詳細ページには何が載っている？">

ビルド詳細ページには、ビルドの種類、プロファイル、Expo SDK バージョン、アプリバージョン、ビルド番号、最後のコミットハッシュ、そしてビルドを開始した開発者またはアカウント所有者が表示されます。

上の画像では、**Build artifact** の現在のステータスがビルド進行中であることを示しています。完了すると、このセクションからビルドをダウンロードできるようになります。**Logs** には、EAS Build 上での iOS ビルドプロセスの各ステップが並びます。ここでは簡潔にするため、各ステップの詳細には触れません。詳しくは [iOS のビルドプロセス](/build-reference/ios-builds/) を参照してください。

</Collapsible>

<Collapsible summary="iOS bundle identifier とは？">

`ios.bundleIdentifier` はアプリの一意な名前です。いまアプリを公開すると、Apple App Store はこのプロパティの値でストア上のアプリを識別します。

この表記は `host.owner.app-name` の形式で定義されます。たとえばサンプルアプリでは `com.owner.stickersmash` となり、`com.owner` がドメイン、`stickersmash` がアプリ名です。

</Collapsible>

</Step>

<Step label="2">

### インストールする

ビルドが完了すると、ターミナル上で EAS CLI が iOS Simulator でビルドを実行するか尋ねてきます。<kbd>Y</kbd> を押します。

<ContentSpotlight
  alt="EAS CLI automatically gives option to run a build on iOS Simulator"
  src="/static/images/tutorial/eas/ios-sim-cli.png"
  className="max-w-[480px]"
/>

<Collapsible summary="別の方法：Expo Orbit を使う">

[Expo Orbit](https://expo.dev/orbit) を使って開発ビルドをインストールすることもできます。EAS ダッシュボードの **Build artifact** から **Open with Expo Orbit** をクリックすると、iOS Simulator に開発ビルドがインストールされます。

</Collapsible>

</Step>

<Step label="3">

### 実行する

プロジェクトディレクトリで `npx expo start` コマンドを実行して開発サーバーを起動します。

<Terminal
  cmd={{
    npm: ['$ npx expo start'],
    yarn: ['$ yarn expo start'],
    pnpm: ['$ pnpm expo start'],
    bun: ['$ bun expo start'],
  }}
/>

ターミナルウィンドウで <kbd>I</kbd> を押すと、iOS Simulator でプロジェクトが開きます。

</Step>
