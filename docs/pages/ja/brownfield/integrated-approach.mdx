React Native と Expo は柔軟性が高く、1 つの画面（あるいは 1 つのビューだけ）単位で段階的に導入できます。この方法で Expo を使うことが自分のアプリケーションに最適だと気づくこともあれば、アプリのより多くの部分に少しずつ導入していくことになる場合もあります。いずれにしても、この柔軟性のおかげで、開発者は完全な書き直しというリスクを冒すことなく、モダンでクロスプラットフォームなツールを既存のネイティブアプリにすぐに導入できます。

このガイドでは、既存のネイティブアプリに React Native のビューを追加する手順を説明します。ここで取り上げるアプローチは、他のライブラリと同じように React Native と Expo を統合することから、私たちが「統合アプローチ」と呼んでいるものです。

> **info** もう一つのよく使われる手法として、私たちが「分離アプローチ」と呼んでいるものがあります。この方法では、Expo アプリはライブラリとしてパッケージ化され、既存のメインアプリケーションからはブラックボックスとして扱われます。詳しくは[分離アプローチガイド](/ja/brownfield/isolated-approach/)を参照してください。

## Expo プロジェクトを作成する

まず、既存のネイティブプロジェクトのルートディレクトリ内に Expo プロジェクトを作成します。

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest my-project --template default@sdk-57'],
    yarn: ['$ yarn create expo-app my-project --template default@sdk-57'],
    pnpm: ['$ pnpm create expo-app my-project --template default@sdk-57'],
    bun: ['$ bun create expo my-project --template default@sdk-57'],
  }}
/>

このコマンドは、新しい Expo プロジェクトを含む **my-project** という名前の新しいディレクトリを作成します。プロジェクト名は自由に付けられますが、このガイドでは一貫性のために **my-project** を使用します。新しいプロジェクトには、始めるのに役立つ TypeScript のサンプルアプリケーションが含まれています。

### monorepo を設定する

monorepo（「モノリシックリポジトリ」）とは、複数のアプリやパッケージを含む単一のリポジトリのことです。[monorepo の扱い方を見る](/ja/guides/monorepos/)を参照してください。

monorepo を設定すると、カスタムのフォルダー構造を使っている場合でも、Android と iOS のスクリプトから Node のライブラリのコマンドを呼び出せるようになります。Yarn の monorepo を設定するには、プロジェクトのルートに **package.json** ファイルを作成し、次の内容を追加します。

```json package.json
{
  "version": "1.0.0",
  "private": true,
  "workspaces": ["my-project"]
}
```

その後、`yarn install` を実行して依存関係をインストールします。これにより、プロジェクトのルートに **node_modules** がインストールされ、ネイティブスクリプトが React Native のコードとやり取りできるようになります。`["my-project"]` は、前の手順で作成した Expo プロジェクトの名前に必ず変更してください。

> **info** monorepo を選ぶ場合は、Gradle/CocoaPods でカスタムのプロジェクトルートを設定する必要があります。これについては次のセクションで説明します。

#### `ReactActivity` を作成する

`ReactActivity` を拡張し、React Native のコードをホストする新しい `Activity` を作成します。この Activity は、React Native ランタイムを起動して React コンポーネントをレンダリングする役割を担います。参考として、[bare minimum テンプレートの **MainActivity.kt**](https://github.com/expo/expo/blob/main/templates/expo-template-bare-minimum/android/app/src/main/java/com/helloworld/MainActivity.kt)を使用できます。

```kotlin MyReactActivity.kt
// package <your-package-here>

import android.os.Build

import com.facebook.react.ReactActivity
import com.facebook.react.ReactActivityDelegate
import com.facebook.react.defaults.DefaultNewArchitectureEntryPoint.fabricEnabled
import com.facebook.react.defaults.DefaultReactActivityDelegate

import expo.modules.ReactActivityDelegateWrapper

class MyReactActivity : ReactActivity() {

  /**
   * Returns the name of the main component registered from JavaScript. This is used to schedule
   * rendering of the component.
   */
  override fun getMainComponentName(): String = "main"

  /**
   * Returns the instance of the [ReactActivityDelegate]. We use [DefaultReactActivityDelegate]
   * which allows you to enable New Architecture with a single boolean flags [fabricEnabled]
   */
  override fun createReactActivityDelegate(): ReactActivityDelegate {
    return ReactActivityDelegateWrapper(
          this,
          BuildConfig.IS_NEW_ARCHITECTURE_ENABLED,
          object : DefaultReactActivityDelegate(
              this,
              mainComponentName,
              fabricEnabled
          ){})
  }
}
```

新しい Activity を **AndroidManifest.xml** ファイルに追加します。React Native の画面の上に `ActionBar` が表示されないよう、`MyReactActivity` のテーマを `Theme.AppCompat.Light.NoActionBar`（または ActionBar を使わない任意のテーマ）に必ず設定してください。

<DiffBlock source="/static/diffs/brownfield/android/android-manifest-add-activity.diff" />

これで、Activity が JavaScript コードを実行する準備が整いました。

### CocoaPods を設定する

プロジェクトに **Podfile** がない場合は、参考として [bare minimum テンプレート](https://github.com/expo/expo/blob/main/templates/expo-template-bare-minimum/ios/Podfile)を使って作成できます。

```rb Podfile
require File.join(File.dirname(`node --print "require.resolve('expo/package.json')"`), "scripts/autolinking")
require File.join(File.dirname(`node --print "require.resolve('react-native/package.json')"`), "scripts/react_native_pods")

require 'json'

platform :ios, '16.4'
install! 'cocoapods',
  :deterministic_uuids => false

prepare_react_native_project!

target 'HelloWorld' do
  use_expo_modules!

  config_command = [
    'npx',
    'expo-modules-autolinking',
    'react-native-config',
    '--json',
    '--platform',
    'ios'
  ]
  config = use_native_modules!(config_command)

  use_frameworks! :linkage => ENV['USE_FRAMEWORKS'].to_sym if ENV['USE_FRAMEWORKS']

  use_react_native!(
    :path => config[:reactNativePath],
    :hermes_enabled => true,
    # An absolute path to your application root.
    :app_path => "#{Pod::Config.instance.installation_root}/..",
    :privacy_file_aggregation_enabled => true,
  )

  post_install do |installer|
    react_native_post_install(
      installer,
      config[:reactNativePath],
      :mac_catalyst_enabled => false,
    )
  end
end
```

すでに **Podfile** がある場合は、React Native の依存関係を既存の **Podfile** に手動でマージする必要があります。

### コードと統合する

次に、React Native ランタイムを起動し、React コンポーネントをレンダリングするよう指示するネイティブコードを追加する必要があります。

#### ReactViewController を作成する

**ReactViewController.swift** という新しいファイルを作成します。これは、React Native のビューを `view` として読み込む `ViewController` になります。

```swift ReactViewController.swift
import UIKit
import React
import React_RCTAppDelegate
import ReactAppDependencyProvider

class ReactNativeViewController: UIViewController {
  var reactNativeFactory: RCTReactNativeFactory?
  var reactNativeFactoryDelegate: RCTReactNativeFactoryDelegate?

  override func viewDidLoad() {
    super.viewDidLoad()
    reactNativeFactoryDelegate = ReactNativeDelegate()
    reactNativeFactoryDelegate!.dependencyProvider = RCTAppDependencyProvider()
    reactNativeFactory = RCTReactNativeFactory(delegate: reactNativeFactoryDelegate!)
    view = reactNativeFactory!.rootViewFactory.view(withModuleName: "HelloWorld")

  }
}

class ReactNativeDelegate: RCTDefaultReactNativeFactoryDelegate {
    override func sourceURL(for bridge: RCTBridge) -> URL? {
      self.bundleURL()
    }

    override func bundleURL() -> URL? {
      #if DEBUG
      RCTBundleURLProvider.sharedSettings().jsBundleURL(forBundleRoot: ".expo/.virtual-metro-entry")
      #else
      Bundle.main.url(forResource: "main", withExtension: "jsbundle")
      #endif
    }

}
```

#### rootViewController で React Native ビューを表示する

最後に、React Native のビューを表示します。そのためには、JS コンテンツを読み込めるビューをホストする新しい View Controller が必要です。すでに最初の `ViewController` があるので、それに `ReactViewController` を表示させることができます。方法はアプリによっていくつか考えられますが、この例では React Native をモーダルで表示するボタンがあるとします。

```swift ViewController.swift
import UIKit

class ViewController: UIViewController {

  var reactViewController: ReactViewController?

  override func viewDidLoad() {
    super.viewDidLoad()
    // Do any additional setup after loading the view.
    self.view.backgroundColor = .systemBackground

    let button = UIButton()
    button.setTitle("Open React Native", for: .normal)
    button.setTitleColor(.systemBlue, for: .normal)
    button.setTitleColor(.blue, for: .highlighted)
    button.addAction(UIAction { [weak self] _ in
      guard let self else { return }
      if reactViewController == nil {
       reactViewController = ReactViewController()
      }
      present(reactViewController!, animated: true)
    }, for: .touchUpInside)
    self.view.addSubview(button)

    button.translatesAutoresizingMaskIntoConstraints = false
    NSLayoutConstraint.activate([
      button.leadingAnchor.constraint(equalTo: self.view.leadingAnchor),
      button.trailingAnchor.constraint(equalTo: self.view.trailingAnchor),
      button.centerXAnchor.constraint(equalTo: self.view.centerXAnchor),
      button.centerYAnchor.constraint(equalTo: self.view.centerYAnchor),
    ])
  }
}
```

## 統合をテストする

これで、アプリケーションと React Native を統合するための基本的な手順がすべて完了しました。React Native ディレクトリで次のコマンドを実行し、[Metro バンドラー](https://metrobundler.dev/)を起動します。

<Terminal
  cmd={{
    npm: ['$ npm run start'],
    yarn: ['$ yarn run start'],
    pnpm: ['$ pnpm run start'],
    bun: ['$ bun run start'],
  }}
/>

Metro は TypeScript のアプリケーションコードをバンドルにビルドし、HTTP サーバー経由でそれを配信し、開発環境の `localhost` からシミュレーター/デバイスへバンドルを共有することで、[hot reloading](https://reactnative.dev/blog/2016/03/24/introducing-hot-reloading) を可能にします。あとは、通常どおりアプリをビルドして実行できます。アプリ内の React で動作する Activity にたどり着くと、開発サーバーから JavaScript コードが読み込まれるはずです。
