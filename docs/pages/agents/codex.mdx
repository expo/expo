Codex is OpenAI's terminal-based AI coding agent. It can read and write files across your project, run terminal commands, and browse the web. Expo projects created with `create-expo-app` are scaffolded with an **AGENTS.md** file that Codex reads directly. It can also check Expo Services and Expo CLI logs, fetch documentation from the Expo Model Context Protocol (MCP) Server, use Expo Skills for best practices, manage your Expo Services deployment workflow, and more.

## Quick start

<Step label="1">

### Install Codex

Install Codex, then start it from any project. For other install methods, see the [Codex CLI documentation](https://developers.openai.com/codex/cli).

<Terminal cmd={['$ curl -fsSL https://chatgpt.com/codex/install.sh | sh']} />

</Step>

<Step label="2">

### Create a new Expo project

Create a project with the following command or ensure your existing project has the latest expo package installed.

<Terminal
  cmd={{
    npm: ['$ npx create-expo-app@latest'],
    yarn: ['$ yarn create expo-app'],
    pnpm: ['$ pnpm create expo-app'],
    bun: ['$ bun create expo'],
  }}
/>

</Step>

<Step label="3">

### Install the Expo plugin

Install the official Expo plugin so Codex knows Expo conventions and can work with your Expo Services projects. The plugin installs Expo Skills and connects Codex to the Expo MCP Server:

<Terminal cmd={['$ codex plugin add expo2@openai-curated-remote']} />

Then sign in to your Expo account. Type `/apps` in a Codex session, search for **Expo2**, and select **Install on ChatGPT**. In the browser window that opens, connect the app and sign in to your Expo account. Then return to Codex and confirm that the install is complete.

The guides below cover the available skills and everything else the MCP Server can do:

<BoxLink
  title="Expo Skills"
  description="Browse the full list of skills the plugin provides, and see install options for other agents."
  href="/skills/#install-expo-skills"
  Icon={Star06Icon}
/>

<BoxLink
  title="Expo MCP Server"
  description="Connect the remote Expo MCP Server to give agents live access to Expo documentation and Expo Services."
  href="/mcp/#installation-and-setup"
  Icon={Star06Icon}

</Step>

<Step label="4">

### Open your project and start prompting

Run Codex from your project root, then describe what you want to do.

<Terminal cmd={['$ cd my-app', '', '$ codex']} />

</Step>

<Step label="5">

### Verify setup

Paste the following prompt in your Codex session to confirm it can read your project:

```text Example prompt
Open package.json and tell me which Expo SDK version this project targets.
```

If the agent replies with the SDK version from **package.json**, the agent is reading your project correctly.

</Step>

## How Codex reads your Expo project

When you start Codex in your project, it reads the scaffolded **AGENTS.md** file. This file points Codex to the documentation for your project's Expo SDK version and holds any project-level instructions you add.

**AGENTS.md** is committed to your project, so a developer's Codex session starts from the same context.

## Use Expo in ChatGPT

ChatGPT and Codex use the same plugin directory, so the official Expo plugin is also available in ChatGPT. Click the following button to open the Expo plugin in the ChatGPT plugin directory:

<Button
  theme="secondary"
  href="https://chatgpt.com/plugins/plugin_asdk_app_6aec576a7d8c8191ab1092de040af13a"
  openInNewTab
  className="mb-4"
  leftSlot={<OpenAILogoIcon className="icon-md text-button-secondary-icon" />}>
  {'Add Expo plugin to ChatGPT'}
</Button>

Install the plugin. Under **Apps** on the plugin page, select **Connect** next to **Expo2**, then sign in to your Expo account. After that, start a new chat and describe your Expo task. Codex uses the same Expo2 app from ChatGPT.

## Example prompts

After setup, describe Expo tasks in plain language. For example:

| Task              | Example prompt                                                                    |
| ----------------- | --------------------------------------------------------------------------------- |
| Upgrade the SDK   | Upgrade this project to the latest Expo SDK and fix any breaking changes.         |
| Add navigation    | Add a tab navigator with Expo Router and a new settings screen.                   |
| Automate builds   | Create a workflow with Expo Workflows that builds the app on every pull request.  |
| Debug a build     | My latest iOS build failed. Read the Expo Build logs and tell me what went wrong. |
| Add notifications | Configure expo-notifications and show a local notification when the app launches. |
| Set up CI/CD      | Create a CI/CD workflow that builds on every PR.                                  |
| Add native UI     | Add a SwiftUI picker component to my Expo app.                                    |
| Check feedback    | Show TestFlight feedback for my app.                                              |
| Verify the UI     | Take a screenshot and verify the blue circle view.                                |

For more examples, see the Example prompts sections of [Expo Skills](/skills/#example-prompts) and [Expo MCP Server](/mcp/#what-does-expo-mcp-server-do).
