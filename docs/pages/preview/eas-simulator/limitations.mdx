> **important** **EAS Simulator is a limited-access preview.** It is not included with paid or free plans and is currently available only to select partners. [Join the waitlist](https://expo.dev/services/simulators) if you are interested in trying it.

EAS Simulator is an experimental preview. Its commands, flags, and behavior can change. This page lists the known limits. For each limit, it also gives the alternative to use.

## Access and versions

| Limit                                                                | Alternative                                                                                                |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Only accounts with limited-access preview access can start sessions. | Check access with `eas simulator:availability`. [Join the waitlist](https://expo.dev/services/simulators). |
| The `simulator:*` commands and flags change often.                   | Use the latest EAS CLI, and read `eas simulator:start --help`.                                             |
| The `--name` flag is not available in older EAS CLI versions.        | Run `npx --yes eas-cli@latest`.                                                                            |

## Platforms and devices

| Limit                                                                                                    | Alternative                                                                                                       |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Android Emulator support is still in development. Some iOS features do not work on Android.              | Use iOS for the browser preview and session recordings.                                                           |
| Android sessions do not have a live browser preview.                                                     | Use screenshots and recordings from the controller.                                                               |
| EAS Simulator does not provide physical devices.                                                         | Use a physical device with local tools or a device cloud.                                                         |
| A session can run only a simulator build on iOS and an APK on Android.                                   | Create an iOS Simulator build or an APK. See [Install your app](/preview/eas-simulator/how-to/install-your-app/). |
| Create session links support only iOS.                                                                   | Use EAS CLI or the REST API for Android.                                                                          |
| Local egress works only on iOS, and it is an experimental feature that must be enabled for your account. | Contact Expo to enable it. See [Network inspection](/preview/eas-simulator/how-it-works/network-inspection/).     |

## Session lifetime

| Limit                                                                                 | Alternative                                                        |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| A session runs for at most 40 minutes on the free plan and 115 minutes on paid plans. | Start a new session when the old one stops.                        |
| A session started with `--non-interactive` does not stop when the command returns.    | Run `eas simulator:stop`, and set `--max-duration-minutes`.        |
| Appium commands and browser preview activity do not reset the idle timer.             | Use `--max-duration-minutes` to limit Appium and browser sessions. |
| `web-preview-only` sessions do not support an idle timeout.                           | Use `--max-duration-minutes`.                                      |
| An idle session can lose its controller connection.                                   | Install and use the app right after the session starts.            |

See [Session lifetime](/preview/eas-simulator/how-it-works/session-lifetime/).

## Controllers and tools

| Limit                                                                                 | Alternative                                                                                                                     |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Each session provisions only the controller of its session type.                      | Start a new session with the type that you need.                                                                                |
| The start flags do not install the app for `appium` sessions.                         | Install the app through your Appium client.                                                                                     |
| **.env.eas-simulator** holds one session at a time.                                   | Use `--out-config-type env` for parallel sessions. See [Agent targeting](/preview/eas-simulator/how-it-works/agent-targeting/). |
| Fast Refresh, React DevTools, and React profiling need Metro and a development build. | Use a development build with a Metro tunnel. See [Iterate on your code](/preview/eas-simulator/how-to/iterate-on-your-code/).   |
| Fast Refresh and React features do not apply to apps that are not React Native apps.  | Use device-level commands. See [Works with](/preview/eas-simulator/works-with/overview/).                                       |
| Argent recordings include a watermark on EAS Simulator.                               | Check the recording before you share it publicly.                                                                               |

## Performance

| Limit                                                                             | Alternative                                                        |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| Startup time varies. A session can wait for concurrency, then take time to start. | Poll the existing session. Do not start a second session to retry. |
| On iOS, accessibility snapshots can take tens of seconds.                         | Wait for the snapshot. Take a new snapshot after a timeout.        |
| The first JavaScript bundle over a Metro tunnel is slow.                          | Wait for the first bundle. Later Fast Refresh updates are fast.    |
| Recordings capture about 30 frames each second.                                   | Use a profiler for frame timing that a recording cannot show.      |

## Data

| Limit                                                                   | Alternative                                   |
| ----------------------------------------------------------------------- | --------------------------------------------- |
| Session logs and artifacts expire 30 days after the session is created. | Download the artifacts that you want to keep. |

See [Security and data](/preview/eas-simulator/reference/security-and-data/).
